## 3. 자세한 설명 (4000자)

```
집 볼 때도 감이 필요하니까.

집감은 국토교통부 실거래가와 입지 정보를 하나의 지수로 정리해, 아파트의 감을 잡도록 돕는 서비스예요. 대전·세종·서울·청주 아파트를 한눈에 비교하고, 직접 가 본 집은 임장 기록으로 남겨 두세요.

■ 한눈에 보는 단지 카드
· 종합 지수와 S~D 등급으로 단지를 빠르게 훑어요
· 최근 거래, 평형별 시세, 층별 시세, 전세·월세까지 한 화면에서 확인해요
· 84㎡ 기준 가격과 가격 흐름(5년·10년), 전고점 대비 위치를 보여 줘요

■ 입지까지 같이 봐요
· 지하철·BRT·기차역 거리, 초등학교, 학원가, 대형마트, 병원
· 학군 점수(중학교 전입·학원가·주변 학원)와 동네 온도 지도
· 소음(큰길·철도), 언덕, 재건축 연한 체크
· 입주 예정 물량으로 앞으로의 공급 흐름까지

■ 조건으로 찾기
· 예산, 평형, 연식, 학교·역과의 거리, 꼭 필요한 조건만 골라 맞는 단지를 찾아요
· 출퇴근지를 정하면 걸리는 시간을 함께 비교해요
· 단지 비교(최대 4곳)와 월 상환액 계산도 있어요

■ 임장을 위한 도구
· 현장 모드: 가서 확인할 항목을 체크리스트로 보고, 들은 호가·메모·사진을 남겨요
· 임장 코스: 여러 단지를 돌 순서와 이동 시간을 짜요
· 관심 단지: 새 거래나 시세 변화가 생기면 알려 줘요(휴대폰 알림은 내가 켠 경우에만)
· 가족과 함께 보기 링크로 임장 기록을 공유해요

■ 카카오 로그인으로 어디서든 이어서
· 로그인하면 관심 단지와 임장 기록이 계정에 저장돼 폰과 PC에서 이어 볼 수 있어요
· 로그인하지 않아도 단지 정보·지도·랭킹은 볼 수 있어요

■ 믿을 수 있게
· 실거래가는 국토교통부 공개 자료, 단지 정보는 공동주택관리정보시스템(K-apt), 공급면적은 건축물대장 기준이에요
· 광고가 없어요
· 산출 방법을 모두 공개해요 (앱 안 '산출 방법')

※ 점수와 등급은 공개된 자료로 계산한 참고용 정보이며 투자 권유가 아니에요. 중요한 결정 전에는 현장 확인과 전문가 상담을 거쳐 주세요.
```

## 5. 그래픽 자산

| 자산 | 규격 | 파일 |
|---|---|---|
| 앱 아이콘 | 512×512 PNG | `android/store/app-icon-512.png` |
| 그래픽 이미지(피처) | 1024×500 | `android/store/feature-graphic-1024x500.png` |
| 휴대폰 스크린샷 | 최소 2장, 최대 8장 (가로·세로 비율 16:9 ~ 9:16, 한 변 320~3840px) | 아래 목록대로 **실제 앱 화면**을 캡처 |

### 스크린샷 구성안 (폰에서 앱을 열어 캡처, 8장 권장)
1. 첫 화면 위쪽: 로고와 지수 1위 카드, 지역 버튼
2. 지도(동네 온도) 화면
3. 단지 페이지 위쪽: 종합 지수·가격·등급
4. 단지 페이지: 평형별·층별 시세
5. 입지 정보(교통·학군·소음)
6. 조건으로 찾기(설문 화면)
7. 현장 모드: 체크리스트와 메모
8. 관심 단지 / 새 소식

주의: 데모 화면(가짜 데이터)은 쓰지 마세요. 실제 사이트 화면에서 캡처해 주세요. 개인 정보(내 이름·메모)가 보이면 가리거나 다른 계정으로 찍어 주세요.

## 7. 데이터 보안 섹션 초안

사이트(앱) 동작에 맞춘 초안이에요. **제출 전에 사실과 같은지 한 번 더 확인해 주세요.**

| 질문 | 답 |
|---|---|
| 수집·공유하는 데이터가 있나요? | 있음 (수집만, **제3자와 공유하지 않음**) |
| 전송 중 암호화 | 예 (HTTPS) |
| 사용자가 데이터 삭제를 요청할 수 있나요? | 예. 앱 안 내 정보에서 '계정과 저장된 기록 삭제' (https://www.jipgam.kr/me.html) |

**수집 데이터 종류** (모두 앱 기능 제공 목적, 로그인한 경우에만, 선택 사항)
| 범주 | 항목 | 이유 |
|---|---|---|
| 개인 정보 | 이름(카카오 닉네임), 사용자 ID | 계정 / 앱 기능 |
| 앱 활동 | 관심 단지, 임장 기록(체크·메모·호가·다녀온 날), 설정 | 앱 기능 |
| 사진 | 임장 노트에 올린 사진 (올린 경우만) | 앱 기능 |
| 기기 또는 기타 ID | 휴대폰 알림 주소(알림을 켠 경우만) | 앱 기능(알림) |

- 위치: 현장 모드·조건 찾기에서 기기 위치를 **기기 안에서만** 쓰고 서버에 저장하지 않음 → 수집 안 함으로 답변 (실제 앱이 서버로 보내는지 제출 전에 한 번 더 확인).
- 광고 ID, 결제 정보, 연락처, 통화·문자 기록은 수집하지 않음.
