# 중학교 특목고·자사고 진학 인원 (학교알리미 '졸업생의 진로 현황')

학교알리미 공시정보 중 **졸업생의 진로 현황**(중학교, 해마다 11월 공시)은 OpenAPI로 제공되지 않아
공시 자료를 받아 이 폴더에 시도코드 이름의 CSV로 넣습니다. 파일이 있으면 빌드할 때 학군 항목
'주변 중학교 특목고·자사고 진학률'에 쓰이고, 없으면 그 항목만 빠집니다.

- `30.csv` 대전, `36.csv` 세종
- 열 (한 줄 = 한 학교의 한 해):

| 열 | 뜻 |
|---|---|
| year | 졸업 연도 (공시 연도) |
| school | 학교 이름 (예: 대전둔산중학교 · 둔산중학교 · 둔산중, 학교알리미 학교 목록과 이름으로 잇습니다) |
| graduates | 졸업자 수 |
| science | 과학고 진학 |
| foreign_intl | 외국어고·국제고 진학 |
| autonomous | 자율형 사립고 진학 (자율형 공립고는 넣지 않음) |
| gifted | 영재학교 진학 (자료에 없으면 0) |

진학률 = 최근 3년 (science + foreign_intl + autonomous + gifted) 합 ÷ 졸업자 합. 졸업자가 50명 미만인 학교는 뺍니다.
