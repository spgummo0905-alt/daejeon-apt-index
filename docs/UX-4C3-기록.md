## 2. 시험하다 알게 된 것
- **통과해도 '사람이 헤맬 곳'은 남아 있음**
  - 프로젝트에 후보가 있으면 '후보 더 찾기'가 화면 맨 아래에 접혀 있음(위치 y≈2930px, 390px 기준). 후보 3곳 이상이면 한참 내려야 보임. 이름은 분명하나 처음 쓰는 사람이 찾을 수 있는지는 사람 시험이 필요.
  - 조건찾기에서 아무것도 안 고르고 '다음'만 8번 누르면 '아직 선택한 조건이 없습니다' 안내가 나옴(막다른 길은 아님).
  - 비교 화면에 단지 1곳만 있으면 '2곳 이상 선택해 주세요'와 추가 입력칸이 함께 보임(화면 확인).
  - 처음 온 사람의 인트로: '궁금한 아파트 찾기' 큰 버튼이 있어 지역을 고르지 않고도 시작 가능. 지역 선택 상자는 위 왼쪽 '대전' 버튼.
- **시험 스크립트 자체의 실수 2건을 고침**: 보이지 않는 검색칸(홈에 입력칸 2개 중 하나는 숨김)을 눌러 실패했고, 접힌 '후보 더 찾기'를 안 펴고 검색칸을 찾았음. 앱 결함이 아니라 시험 순서 문제였음(처음 결과표는 폐기하고 이 결과만 기록).
- 새로고침·뒤로 가기 후 저장 항목이 사라지거나 바뀐 것 없음(5가지 상태 모두).
- 보고서(한 장 정리)에 사진·전화번호 흔적 없음(보고서 글에서 확인; 실제 가족 공유 링크는 확인하지 못함).

## 3. 측정 못 한 것 (정직하게)
- 실제 사람의 완주, 길 잃는 지점의 실제 빈도, 학습 시간.
- 로그인·로그아웃 전환, 계정 동기화 중 실패, 다기기 동시 수정.
- 스크린리더, 키보드 이동 순서, 모바일 키보드가 열린 상태.
- 사진·가족 공유 링크의 실제 서버 시험(사진 저장소가 필요한 항목).

## 4. 판단
자동 시험 기준으로 이 핵심 경로에서 막히는 곳은 없음. 이 결과가 '고객이 헤매지 않는다'를 뜻하지는 않음.
