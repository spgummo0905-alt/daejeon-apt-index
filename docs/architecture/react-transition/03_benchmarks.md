## 운영과 비교 (같은 방식으로 측정한 값만)
- 운영 대전 단지 상세 한 페이지의 스크립트 27개 합계: 압축 후 약 99KB (R0에서 측정, 외부 지도 SDK 포함).
- 따라서 React 런타임 하나만으로 운영 한 페이지 스크립트의 약 2/3에 해당하는 크기가 추가됨. **R0 보고서의 "40~50KB" 추정은 틀렸고 실측 67.8KB가 맞음.**
