비교: `img/c3-compare.png`(목표 비교 / 구현 비교 / 목표 임장 / 구현 임장 코스, 390), `img/c3-sizes.png`(360·430·다크), 흐름 영상 `img/c3-flow.mp4`(비교 → 임장 코스 만들기 → 코스 목록 → 현장 체크).

## 바뀐 것
- **비교**: 고른 단지를 결과 맨 위에 **카드로 나란히**(2곳은 두 칸, 3~4곳은 옆으로 넘김). 카드마다 그림·단지명+등급·지역·연식·84㎡ 추정가·지수. 그 아래 **"먼저 볼 차이" 1~3개**(값이 실제로 다른 항목 중 차이가 큰 순)를 사실만 적어 보여 주고, 이어서 기존 우열 요약·내 조건 기준·핵심 표·더 보기·공유가 그대로 이어집니다. 휴대폰에서 하단 고정 버튼("이 단지들로 임장 코스 만들기")과 겹치지 않게 입력 칸을 접었습니다.
- **임장 코스**: 방문 순서 번호 + **미니 카드**(이름·지역·등급·추정가), 다녀온 단지는 **"다녀옴 11.08" 도장**, 카드 아래에 **큰 파란 "현장 체크 시작 / 이어서 하기" 버튼**(52px)이 기존 현장 모드(`#field`)를 바로 엽니다. 기존 체크리스트·길찾기 줄은 그대로.
- `DJ.hc.col`(세로 카드)을 공통 카드에 추가.

## 변경하지 않은 것
비교 표·우열 계산·내 조건 판정, 코스 순서·거리·길찾기 링크, 방문 기록·체크·메모 저장 키, 공유(링크·그림 카드), URL(`compare.html?s=…`, `my.html#course`).
"먼저 볼 차이"는 새 판정이 아니라 같은 값의 차이만 나열하며, **우열·추천·투자 문구를 쓰지 않습니다.** 가격은 "(추정)"으로 표기.

## 목표 시안과 다른 점
- 시안 비교는 카드가 **크고 건물 그림이 큰 두 장 + 한 줄 요약 + 3~4행 표**지만 구현은 카드가 작고(그림 52px) 요약은 "먼저 볼 차이" 목록입니다. 휴대폰 첫 화면에 카드·차이·하단 버튼을 같이 넣기 위해서입니다.
- 시안 임장은 **"둔산동 아파트 2곳" 코스 헤더 카드, 순서 카드 옆 작은 "현장 체크" 버튼, 체크 항목 바로 노출**이지만 구현은 기존 코스 화면(요약·지도·목록) 안의 단지 목록만 카드로 바꿨고 체크리스트는 접힌 채입니다.
- 시안 비교표의 "교통 좋음/우수" 같은 등급 문구는 없습니다(실제 값만 표시).
- 건물 그림은 평면 추상 그래픽(실제 외관 아님).
