- **앞면**: 단지명(h1)·주소·등급 메달·종합 지수·순위·최근 실거래(눌러서 거래 5건 펼침)·역/학교/세대 배지·**핵심 평가 3개(지수에 들어가는 입지·장기 흐름·5년 흐름)**·준공/세대수/거래건수 칩.
- **"전체 평가 펼치기"**: 기존 6개 평가 막대(지수 반영 3개 + 참고 지표 3개, 구분 유지, 항목 설명) + **실거래 근거 칸**(실거래 가격·면적·날짜·기준일·가격 근거 건수, "추정은 실제 거래가 아님" 안내, 거래 내역/지수 계산 링크). 버튼은 `aria-expanded`, 키보드(Enter/Space), 줄이기 설정 지원. 기본은 접힘.
- 카드 바로 아래에 행동 줄(관심·코스·비교·현장 체크·공유), 그 아래 **가격 구분 칸**(최근 실거래 / 추정·비교용, 면적 기준 안내, 기준일, 내 예산 차이, 현장 확인 버튼)은 기존 그대로.
- 카드 상태 라벨 접근성: 카드 영역이 `h1`을 가리키는 `role=group`.

## 목표 시안과 다른 점 (정직하게)
- **목표 HTML의 CSS 건물 대신 원본 야경 Canvas**를 썼습니다(지시대로). 그래서 시안보다 그림이 좀 더 어둡고 복잡합니다.
- 시안은 첫 화면에 "집의 가치, 한 장에" 큰 문구·탭 칩(단지 상세/비교/임장/MY)·"HOUSE ID / 001"·파란 "관심 카드 저장됨" 고정 버튼이 있지만, **구현은 기존 앱 머리(‹ 단지 상세 · 지역 · ㎡/평)와 기존 하단 "임장 코스에 넣기" 고정 버튼을 유지**했습니다. 시안의 "카드 ID" 문구는 새 ID를 만들지 않으려고 넣지 않았습니다(No.001/51은 기존 순위).
- 시안은 카드 바로 아래 "비교 담기·일조 확인·임장 담기" 3칸이지만 구현은 기존 5개 행동(관심·코스·비교·현장 체크·공유)이고, 휴대폰에서는 첫 화면 맨 아래에서 고정 버튼에 일부 가려져 한 번 내려야 보입니다(기존과 같은 동작).
- 시안의 "이 신분증의 근거 — 근거 보기" 단독 카드는 펼친 카드 안의 "실거래 근거" 칸으로 대신했습니다.
- 시안 첫 화면은 핵심 평가가 3칸+막대 일부가 같이 보이지만 구현은 3칸까지만(펼치기 전).
- 펼친 상태에서 카드가 화면보다 길어집니다(펼치면 한 번 스크롤).
- 아직 안 바꾼 것: 상세 아래쪽 5개 범주 줄·주요 특징 등은 기존 그대로, **비교·임장·MY에서 같은 신분증 축약/기록형을 쓰는 확장은 W2(승인 후)**.
