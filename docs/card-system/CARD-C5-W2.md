비교 이미지: `img/c5-w2-3col-light.png`·`-dark.png`(기존 카드첩 / 목표 HTML MY / 구현, 390), MY·홈·카드첩 나란히 `img/w2b-trio.png`, 동작 영상 `img/w2-flow.mp4`(MY → 카드첩 → 앨범 → 뒤집기 → 되돌리기 → 단지 상세).

## 한 일
- 카드첩·오늘의 카드의 카드(`DJ.miniCard`)를 MY·홈과 같은 **수집 카드 틀**(금속 테두리 + 등급 표기 + 단지명 + 지역 + 집감 지수 + 84㎡ 추정가)로 바꿨습니다. 뒷면(임장 메모)도 같은 테두리 틀입니다.
- **수집 카드를 원본 '남색 금속 + 야경' 모양으로**: 안쪽 바탕은 원본과 같은 등급별 남색/회색 그라데이션, 그림은 단지 상세 카드와 **같은 야경 그림**(`cardgen.js`의 `drawArt`)을 작게 그려 씁니다. 처음엔 남색 바탕+얇은 건물 모양, 그림은 한가할 때 덧그려 화면이 밀리지 않습니다(CLS 0). 그림을 못 불러와도 카드는 보입니다. → 같은 카드 틀을 쓰는 **MY·홈 카드 덱도 함께 같은 모양**이 됩니다.
- 보호한 동작: 카드 뒤집기(탭/Enter/Space), 임장 메모(역·언덕·전세가율 등 기존 `DJ.memo`), 다녀옴 도장(방문 기록이 있는 카드만), 카드 전체 링크(단지 상세), 신고가 띠, `aria-pressed/aria-label`. 저장 키(`favs`·`album`·`visit:`·배지)·계산·URL 변경 없음. 옛 모양은 `housecard.js`가 없을 때를 위해 남겨 둠.
- 같이 고친 것: 홈 카드 덱 첫 카드가 화면 왼쪽 끝에 붙던 것(스크롤 맞춤이 안쪽 여백을 무시) → 줄 시작 위치 16px 확보.

## 목표 시안과 다른 점 (정직하게)
- 목표 MY의 카드는 큰 한 장(지수 94 큰 글자, "다녀옴 ✓" 도장 위치, 'No.001')이고, 구현은 카드첩 한 칸(작은 카드 2열)입니다. 같은 브랜드 가족이지만 **카드 한 장의 크기·정보량이 다릅니다**.
- 시안의 "한 장에 남는 것은 숫자만이 아닙니다" 설명 카드·"한가람 카드 전체 보기" 파란 버튼·상단 탭 칩은 넣지 않았습니다(승인된 방향: 기존 앱 틀 유지).
- 카드 그림은 단지 상세 카드와 같은 **야경 그림(생성 그림)**이고 실제 외관 사진이 아닙니다. 그림 크기가 작아 건물 윤곽 위주로 보입니다.
- 카드 앞면의 지수는 "집감 지수 80점"(글자)로 표기하고 원본처럼 큰 숫자는 쓰지 않았습니다(작은 칸에서 가격과 겹치지 않게).

## 아직 안 한 것 (W2 남은 범위)
- **비교 화면·임장 코스 카드**(이미 C3에서 같은 수집/미니 틀을 쓰는 곳이라 이번엔 건드리지 않음)를 새 야경 수집 카드와 완전히 맞출지는 검수 후 결정.
- 임장 기록(체크·메모)을 카드 **뒷면**에 붙이는 것은 아직 안 했습니다. 지금 뒷면은 기존 '임장 메모'(자료에서 뽑은 참고 값)이며, 내가 적은 체크·메모와는 별도입니다. 공식 지수와 섞지 않으려고 보류했습니다.
