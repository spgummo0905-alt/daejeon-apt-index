# 집감 브랜드 규칙 (대표 색 B안: 딥그린 + 크림)
타겟: 임장·집을 알아보는 20~60대 누구나. 편의성·시인성·디테일 우선. 어르신 전용 기준(글자 18px 강제 등)은 두지 않되 터치칸 44px 이상은 유지.

## 대표 색
| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| 딥그린 900 / 950 | #0a2b24 / #072019 | 첫 화면 바탕, 어두운 면 |
| 딥그린 800 | #0f3d33 | 면, 카드 바탕(어두운 화면) |
| 행동 초록 600 | #13795b | 밝은 화면의 버튼·선택·링크·켜진 탭 (흰 글자 5.4:1, 크림 위 4.9:1) |
| 민트 300 / 200 | #6fd1ae / #9be8cc | 어두운 바탕의 버튼·강조 |
| 크림 | #f7f4ec / #efe9db | 밝은 화면 바탕 / 칩 바탕 |
| 금색 | 기존 `--gold` | S 등급 카드와 작은 강조에만 |

## 지키는 것
- 행동 색은 하나(초록). 한 화면에 같은 일을 하는 버튼 모양은 하나.
- S~D 등급 카드 색(S 금, A 백금, B 파랑, C 슬레이트, D 연회색)과 로고 심볼은 바꾸지 않음. 등급 B의 파랑은 행동 색과 섞이지 않게 카드 안에서만 씀.
- 보라 번짐·그라데이션 장식은 쓰지 않음. 실제 사진과 데이터가 주인공.
- 상태는 색만으로 알리지 않고 글자도 함께.

## 다크패턴 금지 (집감이 하지 않는 것)
가짜 급박함("곧 마감", "지금 N명이 보는 중"), 조회수·광고를 순위에 섞기, 기본으로 체크된 동의, 닫기·건너뛰기 숨기기, 거절 버튼을 흐리게 하기, 강제 알림 유도, 카드 수집을 위해 누르게 만드는 압박.

## 적용 순서
1단계(이 PR): 지역 첫 화면 + 단지 상세. 2단계: 찾기·비교·임장·MY. 3단계: 지도·일조·순위·카드첩(지도·차트 색은 따로 확인).
