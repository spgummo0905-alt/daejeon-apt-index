# WAVE A-4 지도: 좌표 없는 단지 '위치 미확인'
- 좌표(`la`/`ln`)가 없는 단지는 지도에 점을 만들지 않음(임의 위치 금지, 기존 동작 유지). 목록 보기 맨 아래에 `위치 미확인 N곳 · 지도에는 표시하지 못했어요` 제목 + 단지 줄(이름·동네·가격, 누르면 단지 상세). 검색어에 맞는 미확인 단지만, 가격대 칩을 고르면 숨김(가격 필터는 점 기준). 한 번에 최대 30곳.
- 운영 자료 기준 해당: 대전 12·세종 10·청주 12·서울 24곳(이전 점검).
- 검증(좌표를 일부러 지운 시험 자료 3곳): 지도 점 48 / 미확인 3 로 정확히 분리, 라이트·다크 가로 넘침 0·오류 0, 줄 높이 76px. 새 시험 1개 추가, 노드 105 / 파이썬 299.
- 미실시: 운영 자료로 실제 화면 확인(배포 전), 360/430, 글자 125%.
