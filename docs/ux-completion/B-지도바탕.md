# WAVE B 지도 바탕 지도(카카오) 연결
## 결론
- 홈에서 이미 쓰는 **카카오 지도 공개 JavaScript 키**(운영 사이트에 이미 들어 있음)와 같은 SDK를 지도 화면(`map.html`)에 재사용. 새 키·새 도메인 등록·새 비용 없음. 서버 시크릿은 코드에 없음.
- 지도가 뜨면: 실제 지도 위에 가격 핀(묶음→확대하면 핀), 핀 탭 → 같은 아래 요약 시트(단지 상세/일조/후보 담기), 가격대 칩·검색·지도/목록 전환·+/− 모두 기존 로직 재사용.
- 안 뜨면(키 없음·도메인 미등록·쿼터 429·네트워크·SDK 차단): **기존 점 지도가 그대로 대체**, 안내 문구 `바탕 지도를 불러오지 못해 점으로 보여요. 목록으로도 볼 수 있어요`. 빈 화면·무한 로딩 없음.
## 검증 (실제 운영 사이트 데이터·실제 카카오 SDK로 확인)
- 운영 사이트 지도 화면 HTML에 이번 변경(점 지도 요소 + SDK 스크립트)을 입힌 상태로 390×844에서 실행: 실제 카카오 지도(도로·동네 바탕, 대전)에 단지 묶음 63·88·109·124·87·67·14·7 표시, 단지 559곳.
- 4번 확대 후 가격 핀 7개, 핀 탭 → 요약 시트 열림(초원아파트·서구 만년동·5.0억·지수 60점·B등급), 선택 핀이 시트 위에 보임. 지도 위 상아·강변아파트 위치도 만년동 일대로 일치(표본 눈 확인).
- 가짜 SDK 시험(데모 61개 중 51개 좌표): 핀 51, 3억 이하 칩 → 핀 4·개수 4곳, 목록 4행, 목록에서 선택하면 지도로 돌아와 시트 열림, SDK 차단 시 점 지도 51개 + 안내 문구, 오류 0.
- 좌표 자료 점검(운영 `complexes.json`): 대전 559/571, 세종 188/198, 청주 428/440, 서울 3,250/3,274곳에 좌표 있음. 위도·경도 범위 모두 해당 지역 안, lat/lng 순서 뒤집힘 0. 같은 좌표를 공유하는 단지 묶음: 대전 13·세종 1·청주 7·서울 51(같은 단지의 여러 동·단계로 보이나 단지별 확인은 하지 않음).
## 키·요금 체크리스트 (사용자 확인 필요, 시크릿 노출 없음)
- 카카오 개발자 사이트 > 앱 > 플랫폼 키 > JavaScript 키 > **JavaScript SDK 도메인**에 `https://www.jipgam.kr`, `https://jipgam.kr` 등록 여부 (홈 지도가 지금 정상 동작하므로 등록돼 있음).
- [카카오맵] > 사용 설정 **ON**. 공식 문서(developers.kakao.com/docs/ko/kakaomap/common, 2026-07-21 변경 반영): **개발자 계정 기준 첫 번째로 활성화한 앱에만** 무료 쿼터. Web SDK 월 300,000건 무료, 초과 시 비즈월렛 연결·유료 설정 후 건당 0.1원, 미설정 시 429. 집감 앱이 '카카오맵 무료 쿼터' 뱃지가 있는 앱인지 [앱 정보]에서 확인 필요. 사용량은 [통계]>[쿼터]에서 확인.
- 지도 화면이 추가돼 호출이 늘 수 있음(지도 열 때마다 1건으로 가정하면 월 30만 방문까지 무료 범위). 실제 방문량은 모름.
