# WAVE C 일조: 건물을 직접 눌러 동 바꾸기
## 이미 있던 것(중복 작업 안 함)
동 칩, 층 레일(44px 이상 +/−, 층 목록 시트), 시간 슬라이더·±15분, 장면의 고른 층 띠와 해 광선, 선택 동 바뀔 때 시점 240ms 이동(reduced-motion이면 즉시), 건물 클릭 선택(마우스).
## 이번에 바꾼 것 (계산 코드 `preview-calc.js`·`shadow.js`·`preview-iso.js` 변경 없음)
- 입체 그림의 건물을 터치·키보드(Tab, Enter/Space)로 고를 수 있음. 터치와 키보드가 같은 선택 함수 사용. 고른 뒤 포커스 유지. 건물마다 `aria-label`(몇 동 몇 층, 지금 고른 동인지).
- 고를 수 없는 건물(다른 단지 건물, 앞 동 그림자 건물, 높이 자료 없음)을 누르면 이유를 알림: "다른 단지·다른 건물이에요…" 등. 조용히 무시하지 않음.
- 시간 바를 끄는 동안 다시 그리기를 프레임당 1회로 묶음(값·계산·주소 저장은 그대로, 계산은 기존 memo).
- 그림 요소를 `role=img`→`group`으로(안에 누를 수 있는 건물이 들어가 axe `nested-interactive` 방지).
- 포커스 링(노란 윤곽).
## 검증 (로컬 데모 일조 자료)
- 장면 건물 터치 → 513동 선택, 칩·결과(4시간 15분)·시점·층 띠·광선 모두 새 동으로 갱신(스크린샷 라이트/다크).
- 동 3 × 층 3(1·중간·꼭대기) × 시각 10 = 90조합: 광선 상태↔'가림/햇빛' 문구↔✕ 표시↔고른 동·층↔주소 값 **불일치 0**.
- 시간 41번 연속 입력 12ms, 오류 0. axe·가로 넘침 45건 통과(일조 3보기×390/768/1280×라이트/다크 포함). 노드 105 / 파이썬 299.
## 못 한 것·보류
- '한 동 크게 보기' 별도 프리셋: 이미 있는 '전체 보기/가까이 보기' 토글로 대체, 별도 프리셋은 안 만듦.
- 층을 장면에서 직접 누르기: 작은 창 터치는 하지 않기로(층 레일·층별 보기에서 선택). 층별 보기의 층 행 터치는 기존 기능.
- 데모 일조 자료만 사용: 실제 운영 3단지·3,000슬롯 정합성은 기존 시험(`test_preview*.cjs/py`)에 의존, 이번에 운영 자료로 재실행 안 함.
- 360/430 폭 캡처, 글자 125%, 실기기 터치 정확도, 화면 읽기 미확인(NOT_TESTED). 일조 성능 70대(기존) 미개선.
