# WAVE E-2 임장: 방문 순서 카드 + 하단 '현장 체크 시작'
- 후보 카드에 방문 순서 번호(1·2·3 원), 위/아래 버튼(44px). 누르면 프로젝트의 후보 목록 순서만 바뀜(`DJProjects.update`의 slugs, 후보·방문 기록·현장 체크 불변). 이동 거리·시간·ETA는 계산하지 않고 '순서만' 안내문 표시.
- 아래 고정 `N번 ○○ 현장 체크 시작 ›`(56px): 아직 안 다녀온 첫 후보의 기존 현장 체크 패널(`workspace.open("field")`)을 연다. 새 저장 없음. 다 다녀왔으면 첫 후보. 후보가 없으면 숨김.
- 고정 버튼은 위 '지금 할 일' 카드가 보이는 동안·후보 2곳 이상 선택 도크가 떠 있을 때·키보드 열림에서 숨김(다른 버튼을 가리지 않게).
- 후보 카드 격자에 칸(`mv`) 추가, 모바일 줄바꿈 영역 재배치, 이름 정렬 보정.
- 검증(데모): 360/390/430 × 라이트/다크 가로 넘침 0, 오류 0, 이동 버튼 44px, 탭바와 겹침 없음. 순서 바꾸기 실측: 01·02·03 → 02·01·03(저장값 동일하게 변경). 시작 버튼 → 현장 체크 패널 열림. 접근성 15건 통과. 노드 105 / 파이썬 298.
- 미실시: 코스 없음·로그인 필요·저장 실패·사진 권한 오류 UX 시험(계획서 요구), 위치가 있는 후보의 실제 방문 동선 순서 제안(자동 최적화는 안 함), 글자 125%, 실기기 터치.
