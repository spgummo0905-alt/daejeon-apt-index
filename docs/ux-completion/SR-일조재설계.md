## 검증 (로컬 데모 일조 자료, 실제 자료 파일 1건 추가 복사)
- **계산-그림 정합 90조합(동3×층3×시각10) 불일치 0.**
- 일조 있음(512동 8층 동지, 약 2시간)과 **0분(청주 평화 43111-1 가동 1층 동지, 약 0분·가림 라동 9시간 15분)** 둘 다 화면 확인. 0분은 전 단지 계산(737파일)에서 실제로 0분이 나오는 조합을 찾아 사용했고 값은 만들지 않음.
- 건물 터치 → 동 변경, 동 시트 선택/닫힘, 층 ±, 시간 ±15분 → 결과·주소(`#c=…&d=…&f=…`) 동기화, 키보드(Enter/Esc), "원인 보기" 동작, JS 오류 0.
- 360×740 / 390×844 / 430×932 · 라이트/다크 · **글자 125%**: 가로 넘침 0, 44px 미만 터치 0, 이름표 잘림 없음, 시간 바 하단 탭 위 10~16px, **CLS 0.** 접근성(axe)·가로 넘침 45건 통과. reduced-motion 켠 상태에서 측정.
- 시험: 노드 106 / 파이썬 301 통과.
- **성능(로컬 데모, CPU 4배 느리게, 5회 중앙값)**: 로드 중 긴 작업 기준 222ms → 재설계 296ms (편차 큼: 기준 210~400, 재설계 211~867), 시간 이동 8회 기준 361ms → 재설계 338ms. 로드 중 긴 작업은 **약간 늘었을 수 있음**(통계적으로 구분되지 않음). Lighthouse 점수는 이 PR에서 측정하지 않음.

## 시안 대비 정직한 차이
- **가장 큰 차이: 시안의 사실적 3D(창·벽 질감·나무·조경)는 없음.** 장면은 추상 2.5D 면 분리이고, 실제 외관 자료가 없어 사실처럼 그리지 않았습니다. 이 때문에 "토스급" 인상은 시안만큼 나오지 않습니다. 실사 질감을 원하면 경로 B(별도 WebGL 시제품)가 필요하고 성능·배터리 비용을 따로 승인받아야 합니다.
- 시안의 상단 `일조/그림자/시간별` 탭, 하단 `일조 약 6시간` 막대, 층 드롭다운, 플레이 버튼은 만들지 않음(기존 입체/평면/층별, 층 레일 유지).
- 장면 높이는 화면의 약 39%(332/844)로 시안(약 55%)보다 작음. 360×740에서는 253px.
- 건물 터치 시 viewBox 이동/확대(카메라 전환)는 기존 동작 그대로이며 이번에 새로 만들지 않음.
