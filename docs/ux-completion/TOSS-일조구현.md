## 프로토타입에서 옮긴 것 (장식이 아니라 구조·시각)
| 프로토타입 | 구현 |
|---|---|
| 제목 "우리 집 햇살, **눈으로 확인하세요.**" + 부제 | 같은 문구·파란 강조(작은 화면은 부제 생략) |
| 둥근 큰 무대(방사형 하늘색 그라데이션), 좌상단 날짜 칩, 우상단 안내 칩 | 같은 모양. 안내 칩은 "i 추정 안내"(가짜 "예시 화면"이 아님) → 계산 방법·한계 시트 |
| 무대 뒤 해(따뜻한 빛 번짐), 시각에 따라 이동 | 해 위치는 하루 시각·고도만 따라가는 **장식**(건물 그림자 판정과 무관) |
| 선택 동 파랑 그라데이션 / 가리는 동 호박색 / 나머지 옅은 회색 | 실제 데이터로 같은 3계층(기존 가림 판정 그대로). 층 구분선은 층수 자료대로 균등 |
| 노란 층 띠 + 해 쪽 선 | 기존 층 띠·해 쪽 선·✕ 표시 유지(계산값) |
| 무대 위 우측 층 조절 알약(+ 8층 −) | 같은 위치·모양(버튼 44px). 숫자를 누르면 층 목록 시트 |
| 좌하단 "102동·8층 / 건물을 눌러 동을 바꿔보세요" 카드, 우하단 "직접 선택" | 같은 위치. 우하단은 실제 기능(보기 설정: 입체/평면/층별, 전체 보기) |
| 결과 카드(큰 숫자, 알약, 한 줄 이유) | 같은 위계. 숫자·시간대·가림 동은 기존 계산 결과 그대로 |
| 동 버튼 + 날짜 3분할 | 같은 줄. 동은 바텀시트 |
| 시간 카드(큰 시계 + 슬라이더) | 같은 카드. 슬라이더 아래 기존 '가림/일조 색 막대'를 얹음 |
| 파란 "이 단지를 카드로 살펴보기" + ♡ | 같은 배치. ♡는 기존 관심 단지 저장(`DJ.toggleFav`)에 연결 |
| 바텀시트(동 선택·카드), 카드 뒤집기 | 같은 모양·움직임(그리는 입구 220ms, 카드 회전 500ms, 줄이기 설정이면 즉시) |

**가짜 요소는 가져오지 않음**: 상태바 9:41, "디자인 예시 수치", "한가람(예시) 5.1억 가상 가격 78점", 장식 탭바. 카드는 실제 단지 정보(이름·등급·84㎡ 추정 시세·집감 지수·지역)를 `complexes.json`에서 읽고, 없는 값은 칸을 비웁니다. 뒷면 체크 카드에는 실제 직사광 시간이 들어갑니다.

## 기존 기능 연결 (그대로)
`preview-calc.js`·`shadow.js`·일조 자료·주소 형식(`#c=&d=&f=&date=&t=&v=`)·관심 단지 저장·카카오 로그인·사이트 머리글·하단 5탭 모두 변경 없음. `preview-iso.js`는 **그리는 방식만** 변경(색 그라데이션, 층 구분선, 시점, 이름표 위치, 가까이 보기에서 먼 주변 건물 생략). 시점을 28°/52°에서 22°/34°로 낮춰 건물이 판이 아니라 우뚝 선 동으로 보입니다.

## 검증 (로컬 데모 일조 자료 + 실제 0분 단지 파일 1건)
- 계산-그림 정합 **90조합 불일치 0**. 시험: 노드 106 / 파이썬 301 통과.
- 접근성(axe)+가로 넘침 **60건 통과**(일조·평면·층별·0분 × 390/768/1280 × 라이트/다크). 처음 20건 실패(옅은 글자 대비 등)는 글자색을 진하게 고쳐 재검사.
- 360×740 / 390×844 / 430×932 × 라이트/다크 × 일조·가림·0분 + 글자 125%: 가로 넘침 0, 44px 미만 터치 0, JS 오류 0, 화면 흔들림(CLS) 0.
- 동작: 건물 터치, 동 시트(52px 칸), 층 ±·층 목록, 날짜, 시간, 보기 설정, 카드 열기·뒤집기·확인, ♡ 저장(DJ 저장 확인), 안내 시트, Esc 닫기, 원인 보기, 주소 갱신.
- 0분: 청주 평화 43111-1 가동 1층 동지(계산이 실제로 0분을 내는 조합), "직사광이 닿는 시간이 없어요 · 앞 동에 가려져요 · 가림 약 9시간 15분".

## 프로토타입과의 차이 (정직하게)
- **건물 입체감·크기**: 프로토타입은 손으로 그린 단순 직육면체 3개를 정면에서 크게 보여 줍니다. 실제 단지는 건물 13개 이상이 실제 윤곽과 배치로 있어, 같은 크기·질감으로는 못 그립니다. 선택 동과 가리는 동만 크게, 주변은 옅게 두었지만 **"세 동이 큼직하게 서 있는" 인상은 약합니다**. 가까운 비교를 원하면 카메라를 선택 동에 더 붙이는 방식(가까이 보기 확대)이나 B안(WebGL)이 필요합니다.
- 프로토타입 무대 높이는 355px 고정(화면의 42%), 구현은 화면 높이에 맞춰 약 298px(390×844). 시간 카드까지 하단 탭 위에 들어오게 했기 때문입니다. **파란 "카드로 살펴보기" 버튼은 390×844에서 하단 탭에 일부 가려져 스크롤해야 보입니다**(프로토타입은 고정 버튼).
- 건물 이름표는 중요한 2개만(내 동·가리는 동). 프로토타입의 동마다 이름표(101·102·103동)는 없음.
- 장식 해는 선택 시각의 해 방위와 일치하지 않습니다(위치는 하루 진행도 기반). 그림자·✕ 판정은 계산값.
