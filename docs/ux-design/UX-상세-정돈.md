# 단지 상세 정돈 (Visual Quality Sprint 4단계)

문구·구조·계산은 그대로, `static/style.css`의 기존 규칙을 제자리에서 고쳐 표현만 시안에 맞췄다(가격 산출 영역 변경 없음).

## 바뀐 것
- 가격 카드: 회색 면 박스 vs 점선 박스 두 개 → **구분선 하나**. 실거래가 36px로 더 크게, 추정은 24px로 한 단계 낮춤. 두 가격 모두 전용 84㎡ 기준/면적 기준이 다르다는 안내는 띠 대신 글 한 줄(문구 그대로).
- 카드(`.pb`, `.points`, `.to-check`): 선+그림자 → 그림자 하나, 반지름 20.
- 보조 글자 13~14px → 15px, 브레드크럼 15px, 현장 확인 버튼 56px·면 처리.

## 검증(데모 브라우저)
- 단지 상세 3곳 × 5조건(390 라이트/다크, 768, 1280 라이트/다크): 가로 넘침 0, axe 0, 오류 0 (45건).
- 전체 자동 시험: 노드 105 / 파이썬 296 통과. 실제 기기·사람 시험: 미실시.

## 하지 않은 것(후속)
- 시안의 바닥 고정 바 '임장 코스에 넣기'와 상단 5개 아이콘 버튼 정리: 기존 버튼(관심·코스·비교·현장 체크·공유) 기능 연결을 바꾸는 구조 변경이라 별도 승인 후.
