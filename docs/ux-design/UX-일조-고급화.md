# 일조 작업 무대 고급화 (Visual Quality Sprint 3단계)

계산·배치·동작은 그대로(`preview.js`, `preview-calc.js`, `shadow.js`, `preview-iso.js` 변경 없음). `static/preview.css`만 시안·통일 토큰에 맞게 제자리 수정.

## 바뀐 것
- 행동색 #1f66c1, 햇빛색 #ffd166, 반지름 14/카드 20, 보조 글자 #5b6472로 사이트 공통과 일치.
- 카드·결과 카드: 굵은 선 대신 그림자 하나(결과 카드의 2px 검정 테두리 제거). 결과 숫자 40px 굵기 800.
- 칩·±버튼·보조 버튼: 선 대신 면. 세그먼트는 한 종류(바탕 면 + 선택 항목 흰 면)로 통일, 무대 위에 띄운 세그먼트·'전체 보기'는 띄운 그림자.
- 안내 띠(노란 띠+굵은 왼쪽선)는 글 한 줄로. '추정한 참고용' 문구는 그대로 맨 위에 유지.
- 다크: 공통 다크 색으로 맞춤, 장면 안 동 이름이 어두운 바탕에서 안 읽히던 것을 밝은 글자로 수정.
