# 홈 입구 카드 리디자인 (Visual Quality Sprint 2단계)

시안(홈): 검색 → 이어하기 → 핵심 3작업. 기존 입구(찾기·비교·임장/이어하기) 로직(`DJ.activeProject`, 관심 단지 비교 연결)은 그대로 두고 표현만 바꿨다.

## 바뀐 것 (`static/style.css`, 기존 규칙 제자리 수정)
- 입구 카드: 2열 → 세로 한 줄씩. 카드 전체가 버튼(카드 안 채움 버튼 제거, 오른쪽 파란 글자 `› `).
- 남색 큰 면(으뜸 카드)·금색 테두리(임장 입구) 제거: 으뜸 행동은 행동색 선 하나. 금색은 등급에만.
- 카드는 선 대신 그림자 하나, 반지름 20.
- 휴대폰 첫 화면: 긴 설명 줄 숨김, 제목 28px.

## 검증 (데모 브라우저)
- 390 라이트/다크, 768, 1280: 가로 넘침 0, axe 0, 오류 0 (15건). 입구 카드 높이 108~127px, 첫 화면에 3개 모두 보임(264~642px).
- 전체 자동 시험: 노드 105 / 파이썬 296 통과. 기존 시험은 구조(순서·개수·이어하기 연결)를 그대로 확인.
- 실제 기기·사람 시험: 미실시.

## 후속
- 시안의 '핵심 3작업'을 조건 찾기 / 후보 비교 / 일조 보기로 바꾸는 것은 입구 연결(임장 입구) 구조 변경이라 별도 승인 후.
