# 나의 집감: 세 칸 탭 + 다음 행동 (WAVE 4-3)

Fable 자문 3순위. **저장 자료·저장 구조는 건드리지 않고 보이기/가리기만 바꿨다.**

## 바뀐 것
- 긴 세로 나열 대신 세 칸 탭: **내 후보**(관심 단지·로그인 안내) / **임장**(프로젝트 입구·임장 코스·방문 기록·임장 노트·다녀온 단지 비교) / **최근·설정**(최근 본·설정·백업·카드첩·전체 메뉴·홈 화면 추가). 칸 이름 옆에 실제 개수.
- 맨 위 **다음 행동 한 줄**: 담은 단지가 없으면 "조건으로 단지 찾기", 있으면 "임장 코스 만들기", 코스가 있으면 "코스 보기".
- 기존 주소(`my.html#course`, `#notes`, `#my-favs`, `#prefs` 등)로 들어오면 해당 칸이 자동으로 열리고 그 자리로 이동(설정은 펼쳐짐). 마지막 본 칸은 이 탭 안에서만 기억(sessionStorage, 데이터 구조 변경 아님). 스크립트가 꺼져도 전부 보임.
- 기존 시험 2건을 새 구조(세 칸 탭)에 맞게 갱신.

## 측정(데모 브라우저)
- 390 첫 화면 문서 높이: 1,159px (칸 하나만 보임; 이전은 전 구역 세로 나열로 약 2,383px).
- 시험 54건(360/390/430/768/1280, 다크 포함): 칸 전환, 주소로 열기, 새로고침 유지, 가로 넘침 0, 44px, axe 0, 오류 0.
- 전체 자동 시험: 노드 105 / 파이썬 296 통과.
- 실제 사람·실기기: 미실시.
