# 비교: 빈 화면을 "담는 화면"으로 (WAVE 4-2)

Fable 자문(`핵심여정-설계-자문-기록.md`) 2순위. 저장 구조는 건드리지 않았다(관심·최근 본 단지와 주소의 단지 목록만 사용).

## 바뀐 것
- 2곳 미만일 때 "비교할 아파트를 2곳 이상 선택해 주세요" 한 줄 대신: **"N / 2곳 이상" 진행 + 담는 칸 4개 + "N곳 더 담으면 비교할 수 있어요"**.
- 관심·최근 본 단지가 아예 없으면 "조건으로 단지 찾으러 가기" 큰 버튼(이전: 행동 버튼 0개).
- 2곳 이상이면 비교표는 **핵심 6줄**(종합 지수·84㎡ 가격·입지·지하철역·학군 점수·준공)만 먼저, 나머지는 "나머지 N개 항목 더 보기"(접힘, 눌렀는지 aria-expanded 표시). 우위 항목 집계는 전체 항목 기준 그대로.
- 빠른 추가 칩 터치 높이 44px 보장.

## 하지 않은 것
- 정렬·가중치·추천 점수 같은 새 판단(가격 산출 영역), 슬롯 길게 눌러 빼기(기존 칩 ×로 빼기 유지), 바닥 고정 버튼(기존 "임장 코스 만들기" 다음 단계 영역 유지).

## 측정(데모 브라우저, 360/390/430/768/1280, 다크 포함)
- 동작 시험 54건 통과: 처음 0/2·행동 버튼, 관심 칩, 1곳→1/2, 2곳→표(핵심 줄만), 더 보기/접기, 하나 빼면 다시 담는 화면, 가로 넘침 0, 44px, axe 0, 오류 0.
- 전체 자동 시험: 노드 105 / 파이썬 296 통과.
- 실제 사람 시험·실제 기기: 미실시.
