# 조건 찾기: 조건을 바꾸면 바로 보이는 후보 (WAVE 4-1)

Fable 자문(`핵심여정-설계-자문-기록.md`)의 1순위. 이번 PR은 **가장 안전한 핵심만** 반영하고, 큰 구조 변경은 하지 않았다.

## 바뀐 것
- 질문 바로 위에 **"바로 보기" 줄**: 조건을 고를 때마다 지금 맨 위 후보 3곳(평형·가격)과 "N곳 더"가 바뀐다. 누르면 단지 상세로 간다.
- 결과 목록과 **같은 계산**(`list`)을 그대로 쓴다. 새 저장·새 계산 없음. 시험으로 "바로 보기 첫 후보 = 결과 목록 첫 카드"를 확인.
- 조건이 없으면 안내 한 줄, 맞는 단지가 없으면 "조건을 하나 풀어 보세요"(없는 수치를 만들지 않음).
- 줄 높이를 고정(68px)해 화면이 흔들리지 않음.
- 기존 색 대비 부족 2곳(초록 글씨 4.1~4.4:1)을 같은 규칙에서 고침.

## 하지 않은 것 (후속)
- 질문을 칩+바텀시트로 바꾸는 큰 개편, 장식 그림 축소, 카드 [담기]→비교함 토스트: 기존 8개 질문 흐름·저장 구조를 건드리므로 별도 승인 후 진행하는 후속 과제.
