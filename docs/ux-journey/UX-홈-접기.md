# 홈: 긴 분석 구역을 휴대폰에서 접기 (WAVE 4-4)

브리프 "홈: 설명형 섹션을 끝없이 추가하지 말고 검색/지도 터치 + 이어하기 중심으로 간소화". 첫 화면의 검색·세 입구·이어하기는 이미 있어 그대로 두고, **긴 분석 구역만** 정리했다. 자료·계산은 그대로.

## 바뀐 것
- 휴대폰(719px 이하)에서 **동네 온도·입주 물량·구별 비교·입지 대비 가격** 4구역은 제목 + [펼쳐 보기] 버튼만 먼저 보인다(누르면 펼침, aria-expanded 표시). 넓은 화면은 그대로 펼쳐 둠.
- `index.html#heat` 등 기존 주소(전체 메뉴·안내 링크)로 오면 그 구역이 펼쳐지고 그 자리로 이동.
- 접힌 구역이 미리 잡아 둔 높이(2,100px 등)를 쓰지 않게 해서 문서가 실제로 짧아진다.

## 측정(데모 브라우저, 마운트 3회씩)
- 390 문서 높이 10,505px → 6,137px (360: 10,667 → 6,299, 430: 10,483 → 6,115).
- CLS 0 → 0 (360/390/430 각 3회).
- 시험 46건: 접힘/펼침/주소 열기, 44px, 넓은 화면은 접지 않음, 가로 넘침 0, axe 0, 오류 0. 전체 자동 시험 노드 105 / 파이썬 296 통과.
- 실제 사람·기기: 미실시.

## 하지 않은 것
- 지도 핀 탭 바텀시트, 신규 사용자 "관심 지역·예산 한 번 선택" 흐름: 지도·검색 로직을 건드리므로 후속(별도 승인).
