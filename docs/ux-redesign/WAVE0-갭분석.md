## 가장 큰 구조 차이 (먼저 결정이 필요한 것)
1. **하단 탭 의미가 다르다.** 시안 `홈·찾기·비교·임장·MY` / 현재 `홈·찾기·임장 준비·둘러보기·나의 집감`. 시안은 '비교'가 탭이고 '둘러보기(순위)'가 빠진다. 둘러보기(rank.html)를 어디로 옮길지 정해야 한다. → **사용자 결정 필요**
2. **화면 머리 구조.** 시안은 하위 화면 머리가 `‹ 제목 🔍 ◌`, 홈만 `집감` 글자. 현재는 모든 화면이 로고+지역 선택+검색 머리, 그 아래 "파란 소제목 + 두 줄 제목 + 접힌 부제 ⌄" 반복. 앱 느낌을 가장 깎는 부분.
3. **지도는 독립 화면이 아니다.** 현재는 홈 안의 구역(`#map`, 점만 있고 바탕지도 없음). 시안은 전체 화면 지도 + 핀 + 하단 요약 시트. 새 화면(경로)이 필요하고 지도 SDK(`kmap.js`, `aptmap.js` 있음) 확인이 필요.
4. **상세의 고정 CTA·헤더.** 시안은 `‹ 단지 상세`, 이름 위 ♡ ⤴, 아래 고정 '임장 후보에 담기 +'. 현재는 로고 머리 + 배지 + 아이콘 5개 줄, 고정 CTA 없음.
