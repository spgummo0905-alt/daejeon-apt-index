# WAVE 1-b 하단 탭 개편 (사용자 확정 방향)
- 하단 탭: `홈·찾기·비교·임장·MY` (시안과 같음). 아이콘 비교=저울, MY=사람.
- 둘러보기(순위): 탭에서 빠짐. 홈에 `순위·테마·지도` 칩 3개, 찾기의 '찾는 방법' 줄에 `순위로` 추가. `rank.html`·`themes.html` 주소는 그대로.
- 위치 표시: 순위 화면=홈 탭, 비교 화면=비교 탭(전엔 임장 묶음), 테마·역 주변=찾기, 카드첩=MY.
- 옛 `tab-key` 규칙(가운데 강조) 삭제. 시험 기대값 갱신.
- 검증: 4개 화면 × 라이트/다크 가로 넘침 0·오류 0·터치 48px 이상. 노드 105 / 파이썬 296 통과. 이미지 `img/w1b-*.png`.
- 후속: 지도 새 화면은 별도 PR(찾기 '지도/목록' 전환 + 홈 검색에서 진입).
