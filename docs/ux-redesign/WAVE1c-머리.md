# WAVE 1-c 하위 화면 머리 `‹ 제목`
- 휴대폰에서 하위 화면(조건 찾기·테마·역 주변·비교·임장·나의 집감·카드첩·순위·일조·단지 상세) 머리를 `‹ 제목`으로. `‹`은 같은 사이트에서 왔으면 이전 화면, 아니면 홈. 로고·지역 이름은 홈에서 보임(지역 바꾸기·검색·로그인 아이콘은 그대로 오른쪽).
- 제목 위 파란 소제목(`.eyebrow`)은 정리된 화면(`page-hero.lean`, 나의 집감)에서 숨김. 화면 제목과 설명 접기 상자는 그대로.
- 데스크톱 머리는 변경 없음(`‹`은 휴대폰에서만).
