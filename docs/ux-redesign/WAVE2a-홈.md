# WAVE 2-a 홈 입구 카드
- 입구 카드(찾기·비교·임장)를 시안처럼 `아이콘 칸 + 이름 + 제목 + ›` 줄형 카드로. 카드 전체가 버튼. 찾기(으뜸)는 파란 아이콘 칸과 파란 선.
- 이어하기: 기존 `DJ.activeProject` 로직 그대로. 프로젝트가 있으면 임장 카드가 맨 위 으뜸으로 올라가 프로젝트 이름·후보 수·다음 행동을 보여줌(저장 데이터·판단 로직 변경 없음).
- 휴대폰 전용 옛 규칙(작은 카드·버튼 분리)을 새 배치에 맞게 제자리에서 정리.
- 검증: 360/390/430 × 라이트/다크 가로 넘침 0·오류 0. 재방문(프로젝트 3곳) 상태 확인. 노드 105 / 파이썬 296 통과.
- 남은 점: 카드 3개 높이가 커서 첫 화면에서 임장 카드 일부가 가려짐(390×844). 다음 PR에서 높이 축소 검토.
