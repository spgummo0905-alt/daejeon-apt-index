# WAVE 2-b 지도 새 화면 (map.html)
- 점 지도: 단지 좌표를 점으로(바탕 지도·외부 SDK 없음, 화면에 그렇게 밝힘). 이동(끌기)·확대(두 손가락·+/−)·점 누르기. 점 크기는 확대해도 일정.
- 핀 → 하단 요약 시트: 단지명·84㎡ 기준 추정 시세·지수·등급, `단지 상세 ›` / `일조 보기`(미리보기가 열린 단지만) / `후보에 담기`(기존 `DJ.toggleFav` 재사용). 시트는 선택한 점을 가리지 않게 점을 위쪽으로 옮김. Esc·✕·뒤로 가기로 닫힘.
- 지도/목록 전환: 목록은 같은 선택을 쓰는 접근성 대체 화면. 가격대 칩(3·5·7억 이하)·검색.
- 진입: 홈 '지도' 칩, 찾기 '지도에서', 위 메뉴·전체 메뉴. 홈의 기존 카카오 지도 구역(index.html#map)은 그대로 보존.
- 검증: 점 51개, 시트·후보 담기·목록 확인, 접근성·가로 넘침·오류 30건 0, 노드 105 / 파이썬 297 통과. 이미지 `img/w2b-*.png`.
- 한계: 바탕 지도 없음, 데모 가짜 좌표로만 확인(실제 좌표 모양은 배포 후 확인 필요), 홈 검색창→지도 직접 연결은 후속, 실기기·핀치 확대 손가락 실측 NOT_TESTED.
