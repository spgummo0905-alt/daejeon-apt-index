# WAVE 3-a 단지 상세 아래 고정 행동 버튼
- 휴대폰에서 하단 탭 바로 위에 `임장 코스에 넣기 ＋`(56px) 고정. 누르면 기존 '임장 코스' 버튼을 대신 눌러 `임장 코스에 있어요`로 바뀌고, 다시 누르면 뺌. 위치 정보가 없어 코스 버튼이 없는 단지는 `관심 단지에 담기`.
- 새 저장 방식 없음(저장·로그인 확인·한도 안내는 원래 버튼이 그대로). 키보드가 올라오면 숨김, 최근 본 버튼은 위로 비킴, 본문 아래에 여백 확보.
- 검증: 라이트/다크 가로 넘침 0, 오류 0, 버튼 56px, 담기·빼기 왕복 확인. 노드 105 / 파이썬 297 통과.
- 후속: 첫 카드(가격·거래 근거)·범주 탭 정리, 5아이콘 줄 정리.
