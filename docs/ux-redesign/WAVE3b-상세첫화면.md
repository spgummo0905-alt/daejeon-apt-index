# WAVE 3-b 단지 상세 첫 화면
- 휴대폰: 머리 `‹ 단지 상세`와 겹치던 빵부스러기 길(`단지 목록 › 동`)과 별도 일조 링크 띠를 숨기고 가격 카드를 머리 바로 아래로 올림(가격 카드 위치 약 202px).
- 가격 카드 안에 4칸 요약 추가: 집감 지수·등급·세대수·일조(미리보기가 열린 단지) 또는 생활 입지. 모두 이 단지의 실제 값이고 누르면 해당 구역으로 이동. 새 계산 없음.
- 실거래·추정 두 가격, 면적·날짜·근거 건수, '면적 기준이 달라요' 안내는 그대로(가격 근거 표시 보존).
- 검증: 360/390/430 × 라이트/다크 가로 넘침 0·오류 0, 요약 칸 높이 69px. 노드 105 / 파이썬 298 통과.
- 남은 점: 범주 탭(가격·건물·생활환경)은 기존 5줄 범주 목록 유지(탭 전환형은 구조 변경이라 별도).
