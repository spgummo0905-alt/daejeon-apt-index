# WAVE 4-a 비교 화면
- 휴대폰에서 2곳 이상 담았을 때: 설명 상자·예시 버튼·최근 단지 줄을 숨기고 핵심 차이 표를 첫 화면에 올림(표 → 더 보기 → 내 조건 기준 → 단지별 카드 순, 내용 변경 없음).
- 아래 고정 버튼 `이 단지들로 임장 코스 만들기 ›`(56px, 하단 탭 위). 기존 `DJ.addToCourse` 동작 그대로. 키보드가 올라오면 숨김.
- 기준별 우위 칸: 금색 면 → 행동색 면(금색은 등급에만). 판정 로직·'강조한 칸은 상대적 표시' 안내 문구 그대로.
- 기존 접근성 3건(`.gstat.win` 초록 숫자 대비) 함께 수정(변경 전에도 같은 3건).
- 0곳·1곳 상태는 기존 시작 화면 그대로.
- 검증: 360/390/430 × 라이트/다크 가로 넘침 0·오류 0, 고정 버튼 56px, axe 포함 30건 통과. 노드 105 / 파이썬 298.
- 남은 점: 시안의 A/B 단지 사진 카드(상단)는 미구현.
