- 휴대폰: '지금 할 일' 카드를 프로젝트 안 맨 위로(전엔 약 1,444px 아래라 첫 화면에 안 보임). 후보 비교하기·임장 코스 만들기 버튼 52px, 한 줄에 둘.
- 카드 색 남색+금색 → 행동색 면(금색은 등급에만). 프로젝트 데이터·저장·단계 판단 로직(projects.js) 변경 없음, 보이는 순서만 CSS로 변경(지금 할 일 → 이름·조건 → 현황 → 후보 → 단계 → 방문 예정일 → 후보 더 찾기).
- 검증: 프로젝트(후보 3곳) 상태에서 360/390/430 × 라이트/다크 가로 넘침 0·오류 0, axe 포함 30건 통과. 노드 105 / 파이썬 298.
- 남은 점: 시안의 방문 순서 카드(1·2·3)와 하단 고정 '현장 체크 시작'은 미구현(현장 모드 연결은 별도 검토).
