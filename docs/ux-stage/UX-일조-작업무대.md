# 일조 한 화면 작업 무대 (WAVE 2)

## 한 줄 결론
휴대폰(390×844)에서 **스크롤 없이** 결과 · 동 · 날짜 · 층 레일 · 입체 장면 · 시각 슬라이더가 한 화면에 들어온다. 결과 숫자 위치 755px → 151px (스크롤 0회).

## 2안 비교와 채택
Fable(기획 자문, `docs/ux-android/설계-자문-기록.md`)이 제시한 2안 중 **1안(왼쪽 층 레일)** 채택.
- 1안 층 레일: 장면 왼쪽에 세로 층 조절(큰 숫자 + / − / 세로 슬라이더). 숫자를 누르면 층 목록 시트. 건물의 작은 창을 눌러야 하는 방식이 아님.
- 2안 아래쪽 한 줄 조절판: 층·시각을 장면 아래에 모으는 방식. 엄지는 편하지만 장면 높이가 더 줄어 동 이름 표시가 겹쳐서 기각.
채택 사유: 장면 높이를 가장 적게 잃고, 층 조작이 장면 옆에서 바로 보인다.

## 바뀐 것
- 무대 순서: 단지 한 줄(담기·바꾸기) → 동 칩(가로 한 줄) → **결과 카드(약 N시간 · 가장 크게 가리는 동)** → 날짜 → [층 레일 | 입체·평면·층별 장면] → 시각 슬라이더(+/−15분).
- 층 시트: 25층도 한 번에 고르는 큰 칸(48px), 높은 층이 위.
- 동 선택 시 장면 시점이 240ms 부드럽게 이동(동작 줄이기 설정이면 즉시).
- 장면 높이는 화면 크기·하단 탭·키보드(visualViewport)에서 계산해 맞춤. 매우 짧은 화면(640)은 층 슬라이더를 숨기고 + / − 와 층 목록만.
- 단지를 열면 제목은 눈에서만 숨기고(스크린리더는 읽음) 공간을 씀. 한계 문구 "추정한 참고용 · 실내 채광·법적 일조권 아님"은 항상 맨 위에 유지.
- 담기: 기존 관심 단지 저장(`DJ.toggleFav`)을 그대로 사용. 새 저장 칸 없음 → 기존 기록 안전.
- 가림 자세히·그림 보는 법·범례, 현장 확인, 근거·출처는 접힌 칸으로.
- 계산(`preview-calc.js`, `shadow.js`, `preview-iso.js`)은 손대지 않음.
