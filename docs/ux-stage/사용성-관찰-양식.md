# 일조 화면 사용성 관찰 양식 (실제 사람 5명, 설명 없이)

진행자는 화면을 설명하지 않는다. 과제를 읽어 주고 지켜보기만 한다.

| 번호 | 과제(읽어 줄 말) | 성공 기준 | 걸린 시간 | 막힌 곳/표정 | 사용자가 한 말 |
|---|---|---|---|---|---|
| 1 | "이 단지 512동 8층은 겨울에 햇빛이 몇 시간 드는지 알려 주세요." | 결과 숫자를 말함 | | | |
| 2 | "20층으로 바꿔 보세요." | 층이 바뀜(레일·시트 어느 방법이든) | | | |
| 3 | "오후 2시에는 어떤가요?" | 시각을 바꾸고 상태를 말함 | | | |
| 4 | "어느 동이 햇빛을 가리나요? 왜 그런지 설명해 보세요." | 가리는 동과 이유를 자기 말로 설명 | | | |
| 5 | "다른 동으로 바꿔 보세요." | 동 칩 또는 장면 터치 | | | |
| 6 | "이 단지를 저장해 두세요." | 담기 | | | |

기록: 참가자 나이대, 휴대폰 기종, 글자 크기 설정. 성공/실패를 있는 그대로 적는다(없으면 미실시로 둔다).
