# 카드 표지: 밤 건물 그림 → 등급 색 글자 표지 (ux/v2-card-cover)
기준: main `93f75d8`. Fable 5.2와 Opus가 운영 화면에서 같이 지적한 문제(모든 단지에 똑같은 밤 건물 그림, 동 이름 잘림, 작은 영어 라벨)를 고쳤습니다.
방향은 두 모델이 각각 만든 시안을 비교해 정했습니다(Fable의 큰 등급 색 면 + 큰 동 이름 구조, Opus의 숫자 라벨 정리).

## 바꾼 것 (수집 카드: 홈·카드첩·오늘의 카드·갤러리·MY)
- 그림 칸 → **등급 색 글자 표지**: 동 이름 크게(S 금 · A 백금 · B 파랑 · C 슬레이트 · D 연한 중립, 미산정은 점선 테두리).
- 윗줄: 영어 `JIPGAM · S TIER` 제거 → 구 이름 + 등급 배지.
- 그 단지만의 숫자 한 줄: 준공 연도 · 세대수 · 가까운 역까지 거리(없는 값은 생략). 값은 모두 기존 자료 그대로.
- 작은 칸(카드첩 2열·오늘의 카드)은 칸에 맞게 글자 크기를 조절하되 카드 안 글자는 12px 아래로 내려가지 않게.
- 쓰지 않게 된 밤 그림 코드·CSS 정리(`nightArt`, `drawArt` 호출, `.hc-art.hc-night`).

## 하지 않은 것
- 단지 상세 맨 위 큰 카드(`.pb`)와 `cardgen.js`의 PNG 공유 그림은 이번 범위에서 제외(공유 PNG는 별도 렌더).
- 위성 사진(브이월드) 붙이기는 아직 하지 않음(키 노출·표기 방식 확인 후 별도 작업).
