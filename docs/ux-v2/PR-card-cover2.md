# 카드 표지 v2: 그 단지의 실제 항공 사진 (ux/card-cover-v2)
기준: main `a457b3d`. 글자 표지(황토 판)가 싸구려로 보이고 비어 보인다는 지적에 따라, 수집 카드 표지를 **그 단지의 가장 가까운 실제 항공 사진(18단계) 한 장**으로 바꿨습니다.

## 바꾼 것
- 표지 칸: 동 이름 판 → 단지 좌표 기준 항공 사진. 가운데 파란 점이 단지 위치. 카드마다 다른 사진.
- 사진이 단지 가장자리에 걸리면 옆 사진 1~3장을 붙여 단지가 칸 한가운데 오게 함(`static/cover.js`).
- 윗줄을 `서구 · 둔산동`으로 바꿔 동 이름은 글자로 항상 남김. 단지 이름은 22px, 금색은 틀·등급 배지·가격에만.
- 화면에 가까워진 카드만 사진을 요청(IntersectionObserver). 사진은 저장하지 않음. 키는 화면 코드에 없음(서울 Supabase 함수 경유).
- 사진을 못 받거나 서버 주소가 없으면 **칸이 통째로 사라지고** 숫자 줄만 남음(빈 칸·깨진 그림 없음).
- 사진이 하나라도 나오면 화면 아래에 "카드 속 항공 사진 출처: 브이월드(국토교통부) · 촬영 시점이 달라 지금 모습과 다를 수 있어요".

## 하지 않은 것
- 단지 상세 맨 위 큰 카드(`.pb`)와 카드를 PNG로 저장·공유하는 기능은 그대로(사진을 이미지에 합치는 것은 약관 확인 전까지 제외).
- 캐리커처·AI 그림은 만들지 않음(규칙: 실제 사진만).

## 검증
- 실제 단지 12곳 좌표로 카드를 그려 390·360·820·1440 폭 확인: 12장 모두 사진 로드, 가로 넘침 0, 카드 안 최소 글자 14px, JS 오류 0.
- 사진 서버 실패 상태(요청 차단): 12장 모두 칸이 사라지고 카드가 자연스러움.
