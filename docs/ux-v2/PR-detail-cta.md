## 측정 결과
- 위에서 본 단지 칸은 페이지 맨 위에서 약 7,800px 아래(390폭 기준)라서 **첫 화면의 핵심 행동을 밀어내지 않습니다.** 높이를 줄일 필요 없음(변경 없음).
- 다만 점검 중 **다른 문제**를 찾음: 375×667(짧은 폰)에서 페이지를 열면 관심·비교 행동 줄이 하단 메뉴 뒤에 5px만 보이는데도 "보인다"로 판단해 아래 고정 버튼(임장 코스에 넣기)이 숨겨져, **행동 줄도 고정 버튼도 안 보이는 구간**이 생김.
