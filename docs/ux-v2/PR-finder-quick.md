# 찾기 빠른 모드 (ux/v3-finder-quick)
기준: main `a457b3d`. UX v3.1 기획서의 "예산·평형·지역 세 가지만으로 바로 결과" 제안을 구현했습니다.

## 바꾼 것
- 찾기 첫 화면에 **예산 · 평형 · 지역(구)** 세 묶음이 바로 보임. 누를 때마다 남는 단지 수가 각 칸에 표시되고, 맨 아래 대표 버튼이 "맞는 단지 N곳 보기"로 바뀜(56px, 하단 메뉴 바로 위에 붙음). 아무것도 안 골랐을 땐 회색 안내.
- 기존 7개 질문(예산·지역·직장·평형·연식·역·학교·필수 조건)은 **"더 자세한 조건"** 으로 접어 둠. 이미 자세한 조건을 골라 둔 사람, 또는 조건 칩에서 그 조건을 고치려고 들어오는 사람에게는 자동으로 펼쳐짐.
- 세 번 눌러서 결과(데모 61곳 기준 6곳)에 도달. 새로고침해도 고른 조건 유지.

## 바꾸지 않은 것 (시험으로 고정)
- 설문 저장 키(`djdex:survey`)와 값 형식, STEPS 8개의 id·순서, `pass/fit/works/maxPrice` 계산, 주소 조건(`?budget=&py=&gu=…`), 비교함·결과 카드. 빠른 칸은 같은 설문 값 `S`를 읽고 쓰므로 새 저장이 없음.
