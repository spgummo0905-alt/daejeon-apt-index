# 다듬기: 겹침·글자 크기 (ux/v2-polish)
기준: main `bfcf66d`. Fable 5.2와 Opus가 운영 화면 6장에서 같이 지적한 문제 중, **직접 재서 확인된 것**만 고쳤습니다.

## 확인한 것(운영 화면 390px 실측)
- 일조: '최근 본' 떠 있는 버튼이 하단 '카드로 살펴보기' 줄 옆 보조 버튼 위에 걸쳐 있었음 → 확인됨.
- 비교: 파란 고정 버튼이 표 '준공' 줄을 가림 → 가림 자체는 스크롤 중 정상이고, 결과 맨 아래에는 이미 여백(PR 08)이 있어 **변경 없음**.
- 하단 메뉴: 96% 불투명 + 흐림 효과 → 뒤 글자가 살짝 비침, 확인됨.
- 글자: 카드첩 12~13px(`tc-kind`·`tc-hint`·`badge-n`·`badge-name`), 비교 13px(`gstat-*`), 홈 '펼쳐 보기' 버튼 48px, 카드첩 '하나 열어 보기' 44px 등 확인됨.

## 바꾼 것(휴대폰 폭 720px 이하)
- 일조 화면에서만 '최근 본' 떠 있는 버튼을 숨김(다른 화면은 그대로). 처음엔 위로 올렸으나 시간 슬라이더 끝을 가려서 숨기는 쪽으로 정함.
- 하단 메뉴 완전 불투명(흐림 제거).
- 카드첩·오늘의 카드·배지·비교 점수 글자 12~13px → 14px.
- 홈 '펼쳐 보기'·카드첩 '하나 열어 보기'·비교 '비교 결과 공유'·'조건으로 찾기' 버튼 최소 높이 56px.

## 하지 않은 것
- 홈 일부 영문·작은 글자(지도 동 이름 11px은 그림 속 글자), 상세의 태그 11~12px 일괄 상향은 하지 않음(레이아웃이 넓게 바뀌어 별도 검토 필요).
- 카드의 밤 건물 그림→글자 표지 교체, 홈 사진, 비교 2곳 구조 변경은 큰 디자인 결정이라 승인 전에는 하지 않음.

## 검증
일조·카드첩·비교·홈 × 7개 크기(글자 125/200%·다크 포함) 가로 넘침 0·JS 오류 0, 일조 떠 있는 버튼 숨김 확인, axe 60건 통과.
NOT_TESTED: 실제 폰, 스크린리더, 아이폰 사파리, Lighthouse.
