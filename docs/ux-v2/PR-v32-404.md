# 없는 주소(404) 안내 화면 (ux/v32-404)
기준: main `3e2ee15`. UX v3.2 감사 P1 항목 X1.

## 문제
없는 주소를 열면 GitHub 기본 영어 화면("File not found")이 나왔고, 집감 이름·메뉴·돌아갈 버튼이 없고 눌림 칸 4개가 모두 44px 미만이며 375폭에서 가로로 넘쳤음(운영 측정).

## 바꾼 것
- 맨 앞(사이트 맨 위)에 `404.html`을 만들도록 `djdex/landing.py`에 안내 화면을 추가. 집감 로고, "찾으시는 페이지가 없어요", 설명 한 문장, 버튼 2개("집감 홈으로", "내 예산으로 아파트 찾기", 각 56px).
- 어느 주소에서 열려도 깨지지 않게 링크는 모두 절대 주소, 스타일은 파일 안(외부 파일·스크립트 없음). 검색 노출 안 함(noindex).

## 바꾸지 않은 것
- 지역 사이트·URL·저장 키·계산. 기존 페이지는 그대로이고 없는 주소에서만 보임.

## 검증
- 시험 새로 3개(화면 내용, 절대 주소만 사용, 실제 landing 빌드에서 `404.html` 생성).
- 390·375·820에서 가로 넘침 0, 버튼 56px·로고 44px, 본문 18px·보조 15px, axe 위반 0, JS 오류 0.
