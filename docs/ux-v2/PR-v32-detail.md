# 단지 상세: 핵심 행동이 첫 화면에 + 가격 두 숫자가 왜 다른지 (ux/v32-detail)
기준: main `3e2ee15`. UX v3.2 감사 D2, D3, D5와 추천 시안 2B(항상 보이는 임장 코스 버튼).

## 문제 (운영·기준 코드 측정, 같은 조건)
- "임장 코스에 넣기"가 화면 크기마다 다르게 보임: 390×844와 360×740은 스크롤 0~400에서 **없음**(약 800px 내려가야 고정 버튼이 나타남), 375×667은 첫 화면에서 '전체 평가 펼치기'를 덮음.
- 카드 가격 칩은 "8.34억 · 실거래"만 있고 면적이 없어, 아래 추정가(전용 84㎡ 환산)와 숫자가 달라 보이는 이유가 첫 화면에서 안 보임(운영 한가람: 실거래 3.82억은 55㎡, 추정 8.05억은 84㎡ 환산).
- 담은 뒤에도 버튼에 ＋가 남고, 알림에 다음 행동이 없으며 알림이 카드를 덮음.

## 바꾼 것
- 카드 바로 아래에 같은 "임장 코스에 넣기" 버튼(휴대폰, 56px)을 두어 첫 화면에서 보이게. 이 버튼이 화면 밖으로 지나가면 아래 고정 버튼이 나타남 → **모든 스크롤 위치에서 둘 중 하나가 늘 보임**(측정: 기준은 390·360에서 0~400 구간 "없음", 새 코드는 없는 구간 0).
- 카드 가격 칩에 **거래 면적**을 함께 표시(예: `8.34억 136㎡(전용 101) 거래`, ㎡/평 전환 그대로, 좁은 화면에서도 접지 않음). 실거래와 추정 두 칸·"면적 기준이 달라요" 설명은 그대로.
- 담긴 뒤: 버튼은 "임장 코스에 있어요 ✓", 알림에 "코스 보기"(my.html#course) 링크, 알림은 하단 메뉴 바로 위로 내려 카드·가격을 덜 가림.
