# UX v3.3: 낮은 폰 상세 고정 버튼 겹침 + MY 숫자 불일치 (ux/v33-fixes)
기준: main `27441ce`. 감사(UX v3.2)에서 남은 P1·P2 두 건.

## 1. 낮은 폰(높이 700 이하) 단지 상세: 고정 버튼이 '전체 평가 펼치기'를 덮음
- 측정(데모 단지 375×667, 배포된 코드): 카드 아래 버튼과 아래 고정 버튼이 **동시에** 보여 겹치고, '전체 평가 펼치기'(476~524)·카드 끝이 고정 버튼(539~595)에 닿음.
- 원인: 카드 아래 버튼이 하단 메뉴 위에 60%만 보여도 '보인다'로 판단해 고정 버튼을 숨겼는데, 낮은 화면에서는 두 버튼이 겹쳐 보이는 구간이 생김.
- 고침: (1) 태그 칩 줄(준공·재건축·세대·거래)을 낮은 폰에서만 두 줄 대신 **한 줄로 옆으로 넘김**(내용은 그대로) → 카드가 한 줄 낮아짐, (2) 고정 버튼은 카드 아래 버튼이 **온전히(95% 이상)** 보일 때만 비켜 줌. 사진 높이는 그대로(낮추면 가격 칩이 '1위/51' 배지를 가려서 되돌렸음).
- 측정: 375×667에서 고정 버튼이 '전체 평가 펼치기'를 덮지 않고 순위 배지도 보임(눈으로 확인). 390×844는 변화 없음.

## 2. MY: 통계 0·0·0인데 아래는 모두 1
- 문제: 통계 세 칸이 '관심 단지·프로젝트·방문 기록'인데, 아래 안내는 '임장 코스 1곳'(코스 담기는 프로젝트가 아님)이라 같은 화면에서 숫자가 어긋남.
- 고침: 가운데 칸을 **'임장 코스'**로 바꾸고, 아래 안내와 같은 기준(직접 짠 코스만)으로 셈. 저장 키·저장 방식은 그대로(세기만 함).
