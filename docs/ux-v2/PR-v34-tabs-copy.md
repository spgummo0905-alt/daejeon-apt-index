# UX v3.4: 하단 탭 켜짐 통일 + 쉬운 문구 (ux/v34-tabs-copy)
기준: main `27441ce`. Fable 5.2 토스 스타일 점검의 PR 1·2(가장 위험이 낮은 것). 타겟은 임장·집 알아보는 20~60대 누구나라서 글자·버튼 크기를 키우는 일은 하지 않고 편의성·시인성·디테일만 다룸.

## 1. 하단 탭: 어느 화면에서나 켜진 곳이 하나
- 측정(운영 v3.2): 지역 첫 화면(홈)·단지 상세·일조는 켜진 탭이 없었고, 순위는 '홈'이 켜졌음.
- 고침: 지역 첫 화면=홈, 단지 상세·일조·순위=찾기(찾는 흐름의 한 부분). 이미 켜지던 화면(찾기·비교·임장·MY·카드첩·지도·테마·역세권)은 규칙을 그대로 둠.
- 확인(데모 사이트, 390폭): 12개 화면 모두 켜진 탭이 정확히 하나, JS 오류 0.

## 2. 쉬운 말로 (숫자·값·계산 불변, 새 사실·약속 없음)
- 찾기 안내: "조건을 고를수록 좁혀집니다" → "조건을 고르면 맞는 단지 수가 바뀌어요", "…여기에 바로 보여요" → "…바로 보여요" (같은 뜻 반복을 줄임)
- 일조: "318개 단지에서 열려 있어요" → "…에서 볼 수 있어요", 안내 한 곳도 같은 말로
- 지도: "위치 미확인 12곳" → "지도에 없는 단지 12곳"(상세 안내에 '위치 정보가 없어 지도에는 표시하지 못했어요')
- 홈 통계: "지수 산정 단지" → "점수를 매긴 단지"
- 카드첩 뒷면: "눌러서 열기" → "눌러서 단지 보기"

## 바꾸지 않은 것
- 가격·지수·계산·저장 키·URL·일조 엔진. Fable이 제안했지만 결정이 필요한 것(비교 '약 2.4억' 표기 자릿수, 금색 예외, 홈 보라 번짐 제거)은 이번에 넣지 않음.
