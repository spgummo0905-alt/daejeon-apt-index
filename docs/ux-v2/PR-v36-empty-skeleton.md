# UX v3.6: 빈 화면은 '다음에 누를 것 하나', 로딩은 자리표시 (ux/v36-empty-skeleton)
기준: main `b9cd696`. 출처: UX 용어 영상 16편 정리(스킬 ux-vocabulary-ai-direction)의 '빈 화면 9종·로딩 표시' 기준. 옥상 접속 표시는 사용자 결정으로 그대로 둠.

## 한 일
- 빈 화면에 다음 행동 버튼 추가(기존 안내 문장은 그대로): 카드첩(아파트 찾아보기), 임장 프로젝트에 담은 후보가 없을 때(아파트 찾으러 가기), MY 최근 본 단지가 없을 때(지도에서 찾아보기). 버튼 높이 48px.
- 로딩 자리표시(스켈레톤): 현장 모드 창은 '불러오는 중…' 글자 대신 줄·블록 자리표시, 찾기는 조건을 들고 들어올 때 단지 목록이 오기 전 카드 자리 3칸. 목록이 오면 즉시 교체. 움직임 줄이기 설정이면 반짝임 없음. 읽어 주는 도구에는 role=status로 '불러오는 중' 안내.

## 확인 (데모 사이트 390폭)

- 전체 시험 Node 106 / Python 396 통과(새 시험 3개).
