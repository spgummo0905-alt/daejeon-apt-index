## 바꾼 것
- **공용 색 전체 통일:** 행동색 #13795b(어두운 화면 민트 #6fd1ae), 바탕 크림 #f7f4ec(어두운 화면 #0b1f1a), 칩 바탕, 카드첩·MY의 파랑(--hc-blue), 로고 옆 점(보라→초록), 주소창 테마색. 모든 화면이 한 번에 같은 색.
- **지역 첫 화면(폰):** 제목 한 줄 → 검색 → 예산 칩 4개(작은 폰도 한 줄) → 카드 → 주 버튼 순. 설명 글·숫자 줄은 숨김(카드 아래 소개 구간에 이미 있음). 위쪽만 딥그린, 카드 가운데부터 크림. 카드의 세부 막대는 접고 등급·이름·지수·순위만. 주 버튼 초록 채움+흰 글자(5.37:1), 보조는 초록 테두리.
- **상세 "전체 평가 펼치기":** 금 테두리 → 행동 초록 채움(56px). 금색은 등급·점수에만.
- **칩·검색 테두리:** 3:1 이상으로(#5e9483 / 어두운 화면 #4f8f7a).
