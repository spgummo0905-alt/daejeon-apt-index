# UX v3.8: 카드 그림 = 단지 배치도 (ux/v38-card-plan)
기준: #367(공용 색 통일, ux/v37-brand-home) 위. #367이 먼저 병합돼야 함. 운영은 main `b9cd696`.
계기: 카드 속 항공사진은 의미가 약하다는 의견 → AI 이미지(신뢰 문제로 폐기), 규모 그림(특색 없음, 폐기) → 실제 건축물 자료로 그린 배치도.

## 바꾼 것
- 일조 미리보기가 쓰는 건축물 자료(동마다 바닥 모양·층수)를 빌드 때 `plans.json`(동마다 층수·추정 여부·꼭짓점)으로 한 번 더 내보냄. 값을 새로 만들지 않음.
- 카드 사진 칸: 그 단지 자료가 있으면 배치도(북쪽 위, 진한 초록일수록 높은 동, 모든 단지 같은 색 기준), 없으면 기존 항공사진 그대로.
- 배치도 카드엔 "배치도" 또는 "배치도 · 일부 추정" 표시. 화면 아래에 "실제 외관은 아니에요" 안내 한 줄.
- 128px 작은 카드(오늘의 카드)에서는 표시 라벨 숨김.

## 바꾸지 않은 것
일조 엔진·미리보기 자료·좌표·점수·저장·URL, 항공사진 불러오기(자료 없는 단지는 그대로), S~D 카드 색.
