# PR 01 · 앱 셸과 인터랙션 부품 (ux/v2-foundation)
기준: main `b2b0b38`(#335 병합). 이 PR은 **이후 PR이 모두 쓰는 공통 부품**만 만듭니다. 화면 배치는 바꾸지 않았습니다.

## 만든 것
- `static/ux-motion.js`: 모션 수치(`DJ.motion`: 누름 120ms · 전환 220ms · 시트 300ms · 뒤집기 440ms · 도장 380ms · 취소 3.5초), 하단 탭·고정 버튼의 **실제 높이를 변수로 공개**(`--tabbar-height`, `--actionbar-height`), 취소 가능한 알림 `DJ.toastUndo(제목, 본문, 되돌리는 함수)`.
- `static/ux-overlays.js`: **공통 시트** `DJ.sheet.open({title, content, returnFocus})` = 진짜 `<dialog>`(뒷배경 자동 비활성, Esc, 닫기 단추, 배경 누르기, Tab 가둠, 닫으면 눌렀던 곳으로 포커스 복귀, 스크린리더 제목). **맥락 메뉴** `DJ.menu.open(누른 단추, 선택지, {onPick})` = 적은 선택지(정렬·보기)를 누른 자리 아래에 작게, 방향키·Home/End·Esc, 한 번에 하나, 선택 표시(`aria-checked`).
- `static/style.css`: `--ux-*` 수치 변수, 누름 0.98배(120ms), 시트·메뉴 스타일, **모션 줄이기**에서 이동·크기 변화 없이 즉시 교체, 8px 간격 변수.
- `static/app.js`: `DJ.toast`의 `action`이 기존 `href`(링크 단추)에 더해 `onClick`(눌러서 되돌리기)도 받음. 기존 호출은 그대로.
- `templates/base.html`: 위 두 스크립트를 `app.js` 뒤에 **한 번만** 로드(전역 핸들러 중복 방지 장치 `__uxMotion`).
- 누르는 영역: 줄 간격·보이는 크기는 그대로 두고, 문장 속 링크·바닥글 링크·작은 칩의 **누르는 자리만 44px**로 넓힘.
- 시험 `tests/test_ux_foundation.py`(6개) 추가.

## 보존
저장 키·계산·URL·계정 분리·사진 범위: 변경 없음(새 부품은 저장소를 읽거나 쓰지 않음). 기존 시험 수정 없음. 기존 시트(`.sheet`, `pv-sheet`, `mp-sheet`)와 팝업은 **그대로 두었고**, 새 시트를 열 때만 지역·검색·내 기록·최근 본 팝업을 먼저 닫습니다. 기존 시트를 새 부품으로 옮기는 일은 각 화면 PR에서 합니다.

## 상태별 확인 (브라우저, 데모 단지)
- 시트: 열림(모달 true, 제목 연결, 첫 입력으로 포커스, 닫기 44px), **Tab 7번·Shift+Tab 4번 모두 시트 안에서만 순환**, Esc로 닫힘+`ux-lock` 해제+**눌렀던 단추로 포커스 복귀**, 닫기 단추, 연달아 열어도 1개, 열린 지역 팝업은 먼저 닫힘.
- 메뉴: 화면 안에 위치, 항목 44px, 선택 표시, ↓+Enter 선택, 선택 뒤 포커스 복귀·`aria-expanded` 되돌림.
- 취소 알림: 단추 44px, 누르면 되돌리는 함수 1번 호출, **3.3초에 보이고 4.8초에 사라짐**.
- 360×667 · 390×844 · 430×932(다크) · 390 모션 줄이기 · 1280: 모두 같은 결과, JS 오류 0. 누름 전환 0.12s.
- 6개 화면 × 3폭 17조합: 가로 넘침 0, CLS 0.
- **누르는 영역 44px 미만: 홈·찾기·상세·MY·카드첩 5화면 × 360/390/430 = 14조합에서 0** (처음엔 문장 속 링크 등이 15여 개 걸렸고 고쳤습니다).
