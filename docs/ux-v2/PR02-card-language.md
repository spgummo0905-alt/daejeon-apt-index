# PR 02 · 카드 언어 공통화 (ux/v2-card-language)
기준: PR 01(#337) 위에 쌓은 브랜치. 상세·찾기·비교·카드첩·공유 이미지가 **같은 데이터에서 같은 등급 표기**를 쓰는지 맞췄습니다. 카드 값·계산·순위는 그대로입니다.

## 맞춘 것
- **A는 금이 아니라 백금**: 카드첩(수집 카드)의 금 그라디언트가 S·A에 같이 적용돼 있던 것을 S만으로 좁힘. A 칩은 밝은 은백색, 다크에서도 금색이 아님(기준: `static/cardgen.js TIER`, 카드 토큰 `--f*`).
- **미산정은 D가 아닌 별도 상태**(등급 `-`): 점선 테두리 + `?` + "미산정" 글자(색·모양에 더해 글자). 상세 카드 지수 자리 "미산정", 비교 카드 "지수 미산정", 카드첩 푸터 "미산정", 공유 PNG "산정 전"(D의 "아쉬움"으로 읽히지 않게), 스크린리더 "미산정".
- **기울기(tilt)**: 최대 7° → **4°**, 마우스·펜(정밀 포인터)에서만, 터치·모션 줄이기에서는 정지. 카드첩에서 S·A 카드에만 켜짐.
- 값·이름·가격은 건드리지 않음.

## 5등급 대조 (브라우저, 데모 단지 S/A/B/C/D)
상세 카드 · 비교 열 카드 · 찾기 결과 카드 · 카드첩 수집 카드 · 공유 PNG(1050×1470) 5화면×5등급을 `complexes.json` 값과 대조: 등급 글자, 지수, 이름, 가격 **불일치 0**(스크립트 1회차는 D가 비교·찾기에서 안 잡혀 2건으로 나왔으나, 비교는 기본 3곳 한도·찾기는 24곳 '더 보기' 밖이라 화면 조건 때문이었고, 열어서 따로 확인해 일치). 캡처: `img/pr02-grades.png`(카드첩 5등급), `img/pr02-unrated.png`(미산정 상세·비교, 라이트·다크).

## 검증
Node 106 / Python 311(+새 시험 4) 통과, 접근성(axe) 5화면×3폭×라이트·다크 75건 통과, JS 오류 0. 미산정은 **사본 데이터**로만 시험(운영 데이터 변경 없음).

## 하지 않은 것
- 앱 전체 지수·등급 계산, 카드 크기·배치는 그대로(후속 PR 03~).
- 카드첩 모으기 목록에서 미산정 단지는 이전처럼 제외(`GRADES`에 없음) — 모을 수 없는 카드라는 기존 정책을 유지.
- 미산정 상세 카드의 일부 색은 일반 카드 틀을 그대로 써서 "점선 외곽 + ?"로만 구분합니다. 더 강하게 구분하려면 사용자 확인 후 조정.
