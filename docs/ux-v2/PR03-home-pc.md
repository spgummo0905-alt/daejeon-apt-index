# PR 03 · 홈 PC 레이아웃 (ux/v2-home)
기준: PR 02(#338) 위 + main `a4a431a`(#334 병합 포함).

## 문제
PC 폭(901px 이상)에서 홈 오른쪽 '상위 단지 카드'가 **휴대폰용 옆으로 넘기는 줄**로 그려져 있었습니다. 마우스에는 넘기는 동작이 없어서 두 번째 카드가 오른쪽 끝에서 잘려 보였고(글자 "1995…" 잘림), 줄이 열 폭(380px)보다 넓은 412px라 화면 가장자리까지 나갔습니다. 아래 "전체 랭킹 보기" 겹침은 #334가 이미 고쳤습니다.

## 바꾼 것 (CSS만, 901px 이상에서만)
- 오른쪽 열을 380→408px로 조금 넓히고, 카드 줄은 **넘기기 없이 카드 2장을 열 안에 나란히** 보여 줌(각 198px). 3번째 카드는 PC에서 숨김(첫 화면 글·카드 줄이기).
- 휴대폰·태블릿(900px 이하) 넘겨 보기 규칙은 그대로.
- 홈 구조·문구·링크 순서는 변경 없음.

## 검증 (브라우저, 데모)
- 390·820·900·901·950·1100(글자 125%)·1440, 라이트·다크: 가로 넘침 0, PC에서 카드 2장 모두 열 안(`inCol` true), 이름 잘림 없음, 카드첩 박스와 랭킹 링크 간격 6px(겹침 없음), JS 오류 0.
- 900px 이하는 카드 3장 넘겨 보기 그대로(236px).
- 접근성(axe) 홈 × 3폭 × 라이트·다크 통과. Node 106 / Python 311 + 새 시험 3.
