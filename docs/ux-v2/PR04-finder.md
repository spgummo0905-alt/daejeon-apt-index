# PR 04 · 찾기: 조건 칩 고치기 · 비교 담기 · 비교함 (ux/v2-finder)
기준: PR 03(#339) 위에 쌓음. 조건 계산·저장은 그대로이고 **결과 화면의 행동**을 정리했습니다.

## 바꾼 것
- **조건 칩을 눌러 다시 고치기**: 결과 위의 `99억 이하`·`30평대` 칩이 버튼이 되어, 누르면 그 질문 단계로 돌아갑니다(44px, 읽는 이름 "… 조건 고치기").
- **관심과 비교를 따로**: 결과 카드마다 `★ 관심`(기존)과 `비교`(새)가 별개 단추. 비교는 카드 위 줄 오른쪽에 둠(이름이 잘리지 않게).
- **비교함 막대**(결과 영역이 보일 때만, 하단 탭 위): `비교함 2/4` · 비우기 · `나란히 비교하기`(2곳 이상일 때, 기존 `compare.html?s=` 주소 그대로). 1곳일 땐 "1곳 더 고르면 비교해요".
- **담기 직후 취소**(3.5초): 관심 담기, 비교 담기·빼기, 비교함 비우기. 취소하면 원래 선택으로 복구. 알림은 한 번에 하나만 보임.
- **4곳 초과**: 5번째를 누르면 담기 전에 "비교는 4곳까지…"로 알리고 자동으로 빼지 않음.
- **0곳**: 빼면 어떻게 되는지 `○○ 빼면 0곳 → N곳`으로 보여 주되 눌러야만 조건이 풀림(자동 해제 없음).
- **목록 불러오기 실패**: "단지 목록을 불러오지 못했어요 / 다시 시도", 고른 조건은 그대로 남음.
- **키보드**: 입력칸에 커서가 가면 그 칸을 화면 가운데로 올림(비교함 막대·고정 결과 줄은 키보드가 올라오면 숨김 — 기존 `kb-open`).
- 0곳 선택지의 글자 대비(이전부터 있던 axe 5건)를 흐림 처리 대신 읽히는 색+점선으로 고침.

## 보존
`pass`·`fit`·`works`·`maxPrice`, 8개 질문 필드, 설문 저장 키(`survey`), URL `?budget=&py=…`, 결과 정렬·계산: 변경 없음. 비교함은 **새 저장 키를 만들지 않고** 이 화면 안에서만 기억합니다(새로고침하면 비워짐 — 관심은 기존처럼 저장).
