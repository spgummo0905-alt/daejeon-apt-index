# PR 05 · 지도와 미니 카드 연결 (ux/v2-map)
기준: PR 04(#340) 위. 지도에는 이미 핀 → 카드 시트 → 목록 전환이 있어서, **모자란 부분만** 채웠습니다(실제 지도·점 지도 대체, 좌표, 가격·지수 값은 그대로).

## 바꾼 것
- **시트 기본/확장 높이**: 위쪽 손잡이를 누를 수 있는 단추로 만들어(`요약 펼치기/접기`, `aria-expanded`) 펼치면 준공·세대수·가까운 역 줄이 더해집니다. 없는 값은 줄을 만들지 않습니다. 다른 핀을 눌러도 펼침 상태 유지. 시트는 내용만큼 높이(작은 화면에서 넘치면 시트 안에서만 스크롤).
- **위치 미확인 입구**: 가격 줄 오른쪽에 `위치 미확인 N곳 ›`(점선 단추, 44px). 누르면 목록 보기의 해당 영역으로 이동하고 제목에 포커스. 가격대·검색 조건에 같이 반응합니다(이전엔 '전체' 가격대에서만 보였음). 좌표 없는 단지는 지도에 점을 만들지 않습니다.
- **후보 담기 직후 3.5초 취소**, 목록에서 열었다가 닫으면 **목록 보기 버튼으로 포커스 복귀**, 목록에서 단지를 고르면 시트 안 닫기 단추에 포커스.

## 직접 확인한 것 (브라우저, 데모 단지·로컬)
- 핀 선택 → 선택 핀 강조 → 시트 이름·가격이 목록·핀과 같은 값(6.8억 등). 가격대(5억·7억)·검색을 바꿔도 필터 유지, 지도→목록→지도 전환 시 선택 유지(목록에서 현재 단지에 `aria-current`), 주소 `?s=`로 바로 열기.
- 키보드만: 목록 항목 Enter → 시트(닫기에 포커스) → Esc 닫기 → 목록 버튼으로 포커스 복귀, 가격대 필터 유지.
- 카카오 키 없음 → 점 지도 + 안내 문구. 키 있음(가짜 키)+SDK 요청 차단 → "바탕 지도를 불러오지 못해 점으로 보여요. 목록으로도 볼 수 있어요" + 점 51개 + 목록 사용 가능. 좌표 없는 단지 2곳(사본) → 입구 단추·목록 안내·상세 링크 정상.
- 360×667·360×740(글자 125%)·375×667·390(다크)·412(줄이기)·430·768·1280: 가로 넘침 0, 모든 단추 44px 이상, 시트 버튼이 하단 탭에 가려지지 않음. 접근성(axe) 30건 통과. Node 106 / Python 326(+5).
- 지도 화면 레이아웃 흔들림(CLS): 로드·핀 클릭·펼침·접음 모두 0(수정 전과 같은 조건 3회씩 비교, 회귀 없음, 목표 0.02 이하 충족). 처음에 0.08~0.11로 나온 것은 시트가 닫힐 때 숨김 전환을 빠뜨린 중간 상태의 값이었고 고쳤습니다.

## 시행착오 (기록)
- 시트 높이를 62%로 제한했더니 360×667에서 버튼 줄이 탭에 41px 가려졌음 → 수정 전 코드와 비교해 이 PR이 만든 문제임을 확인하고 높이 제한을 '내용만큼 + 넘치면 내부 스크롤'로 바꿔 해결.

## 하지 않은 것·NOT_TESTED
- **실제 카카오 지도 위 동작은 시험하지 못했습니다**(운영 키·도메인이 필요하고 가짜 키는 지도를 못 불러옴). 핀 강조·시트 연결 코드는 기존 방식(`realFocus`, `realPaint`)을 그대로 쓰므로 변경하지 않았지만 화면으로 확인한 것은 점 지도뿐입니다.
- 실제 폰 터치(끌기·두 손가락 확대), 스크린리더 음성, 운영 데이터 대량(수천 핀) 속도, Lighthouse.
