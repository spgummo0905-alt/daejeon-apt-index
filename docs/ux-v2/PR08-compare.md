# PR 08 · 비교 (ux/v2-compare)
방향은 Opus 검토를 거쳐 정했습니다(고정 첫 열 가로 스크롤 표 · 표 위 요소 정리 · 아래 카드 접기).

## 바꾼 것
- **3~4곳**: 표 바로 위에 "← 옆으로 밀어 N곳 모두 보기"와 단지 이름 버튼(44px). 버튼을 누르면 그 단지 열로 이동합니다. 행 라벨(첫 열)은 왼쪽에 고정되고 불투명 배경·경계 그림자가 있어 값과 연결되어 보입니다. 2곳은 안내 없이 그대로 2열.
- **표 접근성**: 표 상자가 키보드로 포커스되어 옆으로 밀 수 있고(`role=region`, 이름표), 열 머리 `scope=col`·행 라벨 `scope=row`. 열 머리의 단지 이름 링크도 누르는 자리 44px.
- **우열 문장 숨김**: "항목별 우위 ○○ 2개…" 문장은 화면에서 숨김(공유 문구 계산에는 그대로). 우열·추천 표현 금지 규칙에 맞춤.
- **아래 단지별 점수 카드는 접음**: 표와 같은 정보라서 "단지별 점수 카드 N장 보기"로 접고 누르면 기존 카드가 그대로 열림(삭제 아님). 4곳 화면 길이 약 3,420px → 약 2,320px.
- **주소 정리**: 같은 단지가 겹치거나 없는 단지, 4곳을 넘는 경우 조용히 빼고 한 줄로 알림. `?s=` `?a=` `?b=` 모두 기존대로.
- 하단 고정 "임장 코스 만들기" 버튼이 표 끝을 가리지 않게 결과 아래 여백 확보.

## 하지 않은 것
- Opus가 제안한 "단지 머리 칩 줄로 교체", "핵심 차이와 내 조건 기준 한 블록 합치기", "임장 코스 버튼을 표 끝으로 이동"은 기존 시험·동작(카드 덱, 내 조건 기준, 고정 버튼)을 크게 바꿔서 이번엔 하지 않았습니다. 다음 라운드 후보.
- 표 머리 줄 고정(세로 스크롤 시 열 머리 유지)은 하지 않음.
- 비교 계산·점수·가격·저장 키는 바꾸지 않음.

## 검증
0/1/2/3/4/5곳·중복·없는 slug·옛 a/b 주소 9가지 모두 의도대로. 비교에서 단지를 빼도 관심 단지는 유지. 9개 크기(360×667·375×667·390 다크·412 줄이기·430·360×740 글자 125%/200%·768·1280)에서 가로 넘침은 표 상자 안에서만, 누르는 자리 44px 미만 0, JS 오류 0. axe 45건 통과. Node 106 / Python 339(+3).
