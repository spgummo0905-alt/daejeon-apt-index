# PR 10 · MY와 카드첩 (ux/v2-my-collection)
기준: main `aefd762`. 수집·도장·저장 방식(`DJ.collect`, `DJ.album`, `DJ.been`)은 바꾸지 않았습니다.

## 먼저 확인한 것 — 이미 있는 것
`cards.js`의 앨범은 이미 `DJ.miniCard`로 새 수집 카드(`DJ.hc.collect`, 금속 테두리·지수·가격)를 그리고, 뒤집기·임장 메모·신고가·다녀옴 도장·'더 보기'·구별 진행·배지가 모두 있었습니다. 그래서 "새 수집형으로 이행"은 이미 끝난 상태로 확인했고 다시 만들지 않았습니다. 카드 수와 분모는 `d.complexes` 실제 지역 데이터에서 계산하며, 새 방문자에게 가짜 카드를 넣지 않습니다(0장이면 빈 안내).

## 바꾼 것
- **걸러 보기 칩**: 전체 · S~D 등급(모은 카드가 있는 등급만) · 다녀옴. 칩 숫자는 모은 카드에서 바로 세어서 보이는 카드 수와 항상 같습니다. 선택은 `aria-pressed`로 알리고, 걸렀을 때 "5장 중 1장 보는 중"을 글로 안내(`role=status`). 칩 44px.
- **등급과 도장의 뜻 구분 문구**: "등급(S~D)은 단지의 지수로 정해지고, 다녀옴 도장은 내가 직접 현장 기록을 남긴 카드에만 찍혀요."

## 하지 않은 것
- MY 화면(`my.html`) 개편은 이번에 하지 않음(이미 상태 요약·내 카드첩·이어할 일이 있어 별도 문제를 찾지 못함).
- 새로 모인 카드의 '새 카드' 표시는 기존 오늘의 카드 흐름이 이미 `DJ.collect` 결과로 보여 주고 있어 변경 없음.
- PNG 생성·키보드 뒤집기·로그아웃 후 데이터 격리는 이번 변경 범위가 아니어서 새로 점검하지 않음(기존 시험 유지).
