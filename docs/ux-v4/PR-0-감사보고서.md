## A. 문제 재현과 근거 화면 (Before)
측정: 데모 사이트와 운영(www.jipgam.kr/daejeon)을 **375×667 / 390×844 / 430×932** 각각 11개 화면(홈·목록·찾기·지도·상세·비교·프로젝트·MY·카드첩·카드3종·일조)로 열어 가로 넘침·오류·터치 칸·탭 구성을 계측했고, 390폭 화면은 눈으로 봤습니다(`img/before-*.png`).
- 가로 넘침 0건, JS 오류 0건, 아래 탭 5개(홈·찾기·비교·임장·MY) 모든 화면에서 동일, 켜진 탭 1개.
- **이미 있는 것(지시서가 제안한 것 중 이미 구현됨)**: 상세 가격판의 "최근 실거래"/"추정·비교용" 분리와 면적 기준 안내(`apt.html` pb-k·pb-note), 비교의 "먼저 볼 차이" 1~3개, 비교 아래 "이 단지들로 임장 코스 만들기", 홈 예산 칩→찾기→상세 **2번 터치**(데모 측정), 찾기 결과 수 즉시 갱신(5억 이하 → 38곳), 빈 상태 다음 행동 버튼(v3.6), 카드 배치도·출처 표시(v3.8).
- **실제 빈틈(근거 있음)**
  1. **탐색이 4갈래**(홈 / 목록 / 찾기 / 지도)로 나뉘고, 찾기에서 고른 예산이 지도로 이어지지 않음: 데모에서 찾기 5억 이하 38곳 → 지도 "전체 51곳"(측정). 찾기 조건은 `djdex:survey` 에 저장되지만 지도·목록은 읽지 않음.
  2. **홈 첫 화면(intro)에는 "이어서 하기"가 없음.** 이어서 볼 집·관심·최근 본 단지는 지역 목록(index) 아래쪽에 있음. 재방문자는 첫 화면에서 처음 온 사람과 같은 화면을 봄.
  3. **MY**: 관심·임장 코스·방문 기록 **0/0/0 세 칸이 똑같이 큼**, 상태(관심→비교→방문 예정→다녀옴)의 구분과 "마지막 하던 일로 돌아가기" 없음. 같은 행동으로 가는 길이 여러 개(검증: v3.6 감사).
  4. **비교→임장은 연결되지만 "차이→현장 체크" 연결이 없음**: "먼저 볼 차이"가 임장 체크 항목으로 넘어가지 않고, "직접 확인할 점" 안내가 비교 화면에 없음(`compare.js`에 없음).
  5. **터치 칸(실측)**: 카드 "임장 메모 보기" 30×30, 일조 시트 "닫기" 39×22, 지도 범례 "A" 32×10, 상세 "거래 내역" 56×18. 푸터 링크·재건축 칩은 보이는 크기는 작지만 `::after` 로 44px 클릭 영역이 이미 있어 **오탐 후보**(확인 못 한 항목으로 표기).
  6. **카드 3종 갤러리**(검수용 화면)는 파란 건물 아이콘 그림을 씀: 3D풍 건물 그림 금지 취향과 어긋남(운영 일반 화면은 아님).
  7. **상세 큰 카드의 야경 건물 그림**: 배치도·항공사진으로 바꿀지 사용자 결정 대기(v3.9부터).
- Phantom 조사(공식 페이지만 열람): **확정 사실** — Explore 탭이 Trade로 통합돼 탐색 장소 감소(help 글), 검색(이름·주소)→자산 페이지, 거래 전 수수료·가격 영향 검토 단계(Swap 도움말), 포트폴리오에 손익·내역(P&L 글). **UX 해석** — 탐색을 한 곳으로 모으고 행동 전 검토를 거침. **집감 제안** — 아래 B. 앱을 직접 로그인해 조작한 것은 아님(NOT_TESTED).
