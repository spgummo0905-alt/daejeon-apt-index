# 광고를 글 읽는 화면에만 (Draft)
승인: 사장님 '필요한 부분에만 광고를 넣자'(2026-11-14). **병합·배포는 직전 배포(#400)가 끝난 뒤, 별도 승인 후.**
## 바꾼 것 (base.html 한 곳 + 시험)
애드센스 코드를 모든 페이지 머리에서 빼고, **단지 상세·랭킹·테마·역별·산출 방법** 5종에만 둠. 찾기·비교·지도·MY·홈·코스·카드첩·프로젝트·내 정보·옥상·소개·약관·방침·미리보기·관리자에는 넣지 않음. 지역(대전·세종·서울·청주)은 같은 템플릿이라 모두 적용. 데모 빌드·광고 ID 없는 빌드에는 원래대로 안 나옴.
## 이유
광고를 넣으니 운영 대전 홈 휴대폰 점수가 성능 73~74 / 모범사례 73~77로 내려감(광고 막으면 80 / 100, 쿠키 때문). 도구처럼 쓰는 화면에서 광고를 빼 속도·방해를 줄이고, 글 읽는 화면에서만 수익을 얻음.
## 확인
- 데모 빌드(광고 코드가 나오게 임시 조건 풀어서): 광고 있음 = apt 61·rank·themes·stations·methodology, 없음 = index·finder·compare·map·my·course·cards·projects·rooftop·intro 등 13종.
- 새 시험 5개: 읽는 화면 O, 쓰는 화면 X, 데모·ID 없음 X, base.html 목록과 시험 목록 일치, 처리방침의 광고 안내 유지. 조건을 일부러 빼면 시험이 실패함(변이 확인).
- 전체 시험: Node 116 / Python 502 통과.
## 알려진 한계 / NOT_TESTED
- 처리방침의 광고 안내(애드센스·광고 쿠키)는 광고가 일부 화면에만 있어도 그대로 둠(사이트 전체에 해당하는 안내라 안전한 쪽).
- 애드센스 자동 광고를 켜 두었다면 위 5종에서만 뜸. 광고 노출은 애드센스 승인·설정에 달려 있어 확인하지 못함.
- 운영 점수 효과는 배포 후 재서 확인 예정.
- 앱(TWA) 안 화면에서의 광고 노출은 확인하지 못함.
