# C3 작은 그림 + 목록 실패 안내가 안 보이던 문제 (사장님 위임: '알아서 진행')
시안: Drive `시안/C3-작은그림4종-*.png`. 이번에는 실제 쓸 곳이 분명한 2곳만 넣음.
## 한 것
- **빈 카드첩**: 책+집 선 그림(장식, aria-hidden). 문장·버튼 그대로.
- **단지 목록 불러오기 실패(찾기)**: 끊긴 와이파이 선 그림 + 기존 문구·'다시 시도' 그대로.
- **발견한 진짜 문제**: 목록을 못 불러왔을 때 안내와 '다시 시도' 버튼이 닫혀 있는 '더 자세한 조건' 상자 안에 들어가 **화면에 안 보임**(운영에서 같은 상황을 만들어 확인: 제목·버튼 모두 보이지 않음). 실패했을 때 상자를 열어 보이게 함(기존 문구는 그대로).
- 외부 파일·글꼴·움직임 0. 직접 그린 선 그림 2개. 색은 기존 등급색·금색 규칙과 겹치지 않게 중성색 사용(기존 시험이 잡아 줘서 수정).
## 하지 않은 것
첫 임장 핀·저장 완료 체크 그림은 쓸 화면 문구와 저장 규칙(성공 확인 뒤에만)을 건드려야 해서 보류. 실패에는 성공색을 쓰지 않음.
