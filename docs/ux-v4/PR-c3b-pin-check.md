# C3 보강: 저장 완료 체크 + 첫 임장 핀 (사장님 질문 '왜 못한다는거야?' 후 진행)
앞 PR(#412)에서 보류했던 두 그림을 넣음. 보류 이유는 '저장 확인 뒤에만 성공 표시' 규칙을 건드릴까 봐였고, 기존 코드를 읽어 보니 안전하게 붙일 수 있었음.
## 저장 완료 체크
- 현장 모드 저장 줄(`paintSave`)이 **'이 기기와 내 계정에 저장됐어요.'일 때만** `ok` 표시를 붙임(체크 원 그림, CSS 데이터 그림 1개, 외부 파일 0, 움직임 0).
- 비로그인('이 기기에 저장돼요')·보내는 중·계정 실패에는 붙지 않음. 실패는 기존 빨간 안내 그대로.
## 첫 임장 핀
- MY '임장' 탭에 방문 기록이 **하나도 없을 때만** '첫 임장을 기록해 보세요' 안내(핀 그림, 장식, 문장+버튼). 기록이 생기면 사라짐(데모에서 방문 기록 1건 만들어 확인).
## 확인
- 데모: 저장 상태 4가지(비로그인/보내는 중/실패/완료) x 320·390 밝은·어두운 모두 체크는 '완료'에서만. 핀 안내 320·390 가로 넘침 0, 버튼 48px.
- 새 시험 4개 + 변이 5종(실패에도 체크·보내는 중에도 체크·전환 제거·핀 항상 보임·외부 주소) 모두 실패 확인. 전체 Node 116 / Python 549 통과.
- 시험 작성 중 '아무것도 검사하지 않는 줄(or True)'을 넣었다가 스스로 찾아 지우고 진짜 검사로 바꿈.
