# C5 완료 카드 (시안 PDF 7쪽 '완료' 화면, 사장님 승인 'ㅇㅇ/ㅇㅋ')
현장 모드에서 '오늘 다녀왔어요'가 **실제로 저장된 직후에만** 완료 카드를 보임: 큰 체크 원 · '첫 임장 기록이 남았어요!'(다녀온 단지가 하나뿐일 때, 아니면 '임장 기록이 남았어요') · '이 기기에 저장됐어요.' · '<단지> · 11.15 방문 도장' · '내 카드첩에서 보기'(기존 cards.html 링크).
## 지킨 규칙
- 저장 실패·끄기에는 카드를 만들지 않음(성공색 없음). 시안·지시서의 '저장 확인 뒤에만' 규칙.
- 값·저장 키·형식·동기화 코드 변경 0. 새 값 계산 없음(다녀온 날짜 수만 기존 기록에서 읽음).
- 시안의 한가람/11.14는 예시이므로 실제 단지 이름·날짜 사용. 움직임은 기존 카드 등장(card-in) 240ms 한 번, 줄이기 설정이면 없음.
- 아래 고정 줄과 기존 알림창에 가려지지 않게 위로 올려 보여 줌(`scroll-margin-bottom`).
## 확인 (데모, 320·390·412 · 밝은/어두운)
저장 성공으로 켜기 → 카드 보임 / 끄기 → 숨김 / 저장 실패(saveVisit=false) 켜기 → 안 보임. 버튼 52px, 가로 넘침 0, 카드가 고정 줄·알림창 위에 전부 보임.
새 시험 5개 + 변이 5종(저장 전 표시·끌 때도 표시·처음부터 보임·첫 임장 문구·저장 전 표시 재확인) 모두 실패 확인. 기존 시험 2개가 이번 변경(줄 형태, 파일 끝 검사)에 걸려 시험 쪽을 고침(규칙 완화 아님). 전체 Node 116 / Python 554 통과.
