# C6 빈 카드첩 시안 모양 (시안 PDF 12쪽 '빈 상태', 사장님 승인 'ㅇㅇ/ㅇㅋ')
카드가 한 장도 없을 때의 카드첩 빈 안내를 시안처럼: 가운데 정렬 카드 · 큰 원 안 책 그림(장식) · '첫 카드를 기다리고 있어요' · 기존 설명 문장 그대로 · 진한 초록 알약 버튼 하나('아파트 찾아보기', 56px) · 아래 '인터넷이 불안정한가요? 기록이 저장되지 않았다면 성공 도장을 숨겨요.' 안내 띠.
## 지킨 규칙
- 문장·링크 변경 없음(제목 한 줄 추가). #387의 '한 문장 + 버튼 하나' 구조 유지, 설명문·버튼 늘리지 않음.
- 안내 띠는 글자만, 성공을 말하지 않음. 카드가 모이면 빈 안내와 안내 띠 둘 다 사라짐(데모에서 단지를 열어 확인).
- 그림은 직접 그린 SVG, 외부 파일·움직임 0, aria-hidden. 값·저장 코드 변경 0.
## 확인 (데모, 320·390 밝은/어두운)
빈 상태에서 보임 · 버튼 56px · 가로 넘침 0 · 단지를 열면 사라짐. 새 시험 4개 + 변이 4종 실패 확인(그림 장식 변이는 처음 시험이 못 잡아 시험을 고침). 기존 시험 2개가 구조 클래스에 걸려 코드를 시험 쪽 구조(`album-empty empty-next`)에 맞춤. 전체 Node 116 / Python 553 통과.
