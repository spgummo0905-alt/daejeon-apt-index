# C7 카드첩 시안 모양 (시안 PDF 8쪽, 사장님 승인 'ㅇㅇ/ㅇㅋ')
카드첩 '살펴본 아파트 카드' 위쪽에 시안의 두 요소를 추가:
- **민트 안내 띠**: 반짝 아이콘 + '수집한 기록이 차곡차곡' + '방문 도장은 실제 임장 기록에만'.
- **내 카드 모아보기 타일**: 내가 **실제로 모은 카드**에서 등급마다 지수 최고 한 장(최대 3장)을 진한 남색 타일로(등급 배지 + 단지명, 누르면 그 단지로). S만 금테, A는 금색 없음.
## 지킨 규칙
- 둘 다 모은 카드가 있을 때만 보임(빈 상태에서는 C6의 빈 안내만). 모으지 않은 카드는 절대 뽑지 않음. 값·지수·등급 계산·저장 변경 0, 새 라이브러리·외부 파일·움직임 0.
- 시안의 '한가람 94'는 예시: 실제 모은 카드 값만 씀. 시안의 큰 카드 한 장 영역은 기존 카드 그리드가 그 역할(카드 뒷면·가짜 희귀도 없음).
## 확인 (데모 카드 5장 모음, 320·390 밝은/어두운)
빈 상태: 띠·타일 없음 / 5장 모은 뒤: 띠 + 타일 B·C·D 3개(높이 84~87px), 가로 넘침 0, 화면 오류 0. 어두운 화면에서 띠가 바탕에 묻혀 얇은 테두리 추가. 새 시험 5개 + 변이 4종(모으지 않은 카드 뽑음·카드 없어도 띠·최저 지수·A 금색) 모두 실패 확인. 전체 Node 116 / Python 563 통과.
## NOT_TESTED
실제 폰, 아이폰, 글자 125·200%, S·A 카드가 있는 실제 계정(데모에는 S·A를 모은 상태가 없어 S 금테·A 타일은 코드/시험으로만 확인).
