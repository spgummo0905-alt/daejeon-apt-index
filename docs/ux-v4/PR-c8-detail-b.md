# C8 상세 화면 시안 B (사장님 선택: '시안B로 가자', PDF 7쪽 방향)
휴대폰 단지 상세에서 카드의 **위치 지도·거리 줄·점수 줄·칩 줄**을 '입지 보기' 단추 뒤로 접고, 카드 바로 아래에 두 칸을 둠.
- **입지 보기**(연두): 누르면 카드 안에서 위치 지도·직선거리·시설 거리·점수 줄이 펼쳐짐, 다시 누르면 접힘(`aria-expanded`).
- **다른 집과 비교**(분홍): 기존 비교 링크(`compare.html?a=<단지>`) 그대로.
- 첫 화면에 이름·등급·지수·**실거래·추정 가격**(실거래와 추정을 따로 보이는 구분과 문구 그대로)이 들어옴. 임장 코스 버튼은 기존 그대로.
## 지킨 규칙
- 값·문구·계산·URL·저장 변경 0. 접는 것은 CSS 표시만이고 마크업은 그대로(검색·공유 영향 없음). 단추(JS)가 없으면 접지 않음. **데스크톱은 변화 없음**(두 칸은 휴대폰 폭 719px 이하에서만).
- 가격 줄·이름·등급·지수는 접지 않음(시험으로 고정). 움직임·외부 파일 0.
## 확인 (데모, 320·390·412 밝은/어두운, 데스크톱 1280)
접힘/펼침/다시 접힘 상태 전환, 가로 넘침 0, 화면 오류 0, 첫 화면에 가격 포함. 두 칸이 고정 버튼에 14px 가려져 칸 높이를 84→72px로 줄여 390·412폭에서 해결(360폭·낮은 화면은 스크롤하면 보임). 데스크톱 1280은 지도·거리 그대로 보임.
새 시험 6개 + 변이 5종(가격 줄 접음·데스크톱에도 접음·단추 없이 접음·비교 링크 변경·aria 제거) 모두 실패 확인. 전체 Node 116 / Python 564 통과.
