# C9 글자 크기 125%·200% 대응 (지시서 C4 마무리 검증에서 발견)
휴대폰 글자를 키우면(접근성 글자 크기) 상세 화면 여러 곳이 옆으로 넘치던 것을 고침. 글자는 줄이지 않고 줄바꿈되게 함. 값·문구·계산 변경 0.
## 원인(운영에서 재서 찾음)
- 상세 카드 가격 두 칸: 글자 폭만큼 칸이 늘어남 → 칸 폭 고정(`minmax(0,1fr)`).
- 긴 단지명(예: 서울 `현대8차(성수현대:91~95동)`): 320폭에서 점수 칸이 자리를 먹어 이름이 한 글자씩 세로로 쌓임(17줄) → 400px 이하에서 점수·순위를 이름 아래 한 줄로.
- 줄바꿈 금지(`white-space: nowrap`)가 걸려 칸을 밀던 곳: 핵심 포인트 값, 입지 하위 %, 면적 표기, 시세 표, 칩 줄, 하단 탭, 카드첩 지역 표, 찾기 제목.
## 확인(데모, 글자 100·125·200% × 320·360·390·430폭 × 상세·카드첩·찾기·MY·홈 = 60조합)
고치기 전: 125%에서 320폭 11px, 200%에서 최대 193px 넘침(카드첩 19, 찾기 6 포함). 고친 뒤: 60조합 모두 가로 넘침 0, 가격 칸 안 글자 삐져나옴 0. 화면으로 200%(390폭)와 긴 이름(320폭) 확인.
새 시험 5개 + 변이 5종(가격칸 폭 고정 제거·점수 이름 옆 복귀·줄바꿈 금지 복귀·칩 줄 줄바꿈 제거·글자 줄여서 해결) 모두 실패 확인. 전체 Node 116 / Python 574.
