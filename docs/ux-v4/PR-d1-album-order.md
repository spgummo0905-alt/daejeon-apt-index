# D1 카드첩 순서 (사장님 확정: 시안대로, 카드첩 카드는 위성사진)
시안(C9~C12 번들) 카드첩처럼 **맨 위에 '내가 모은 집들'과 모은 카드**가 오게 순서를 바꿈. 이전에는 '오늘의 비교 후보'와 '임장 배지'가 위에 있어 모은 카드가 약 2,468px 아래에 있었음.
- 제목: '살펴본 아파트와 임장 기록' → **내가 모은 집들** + 한 줄 '직접 살펴본 단지가 기록으로 남습니다.' (검색에 보이는 페이지 제목 '카드첩 · 임장 기록 · 집감'은 그대로)
- 구역 순서: 모은 카드(#album) → 오늘의 비교 후보(#today) → 임장 배지(#badges)
- 모은 카드 구역 안: 안내 띠 → 내 카드 모아보기 → **걸러보기 칩 → 카드 격자** → 등급별 칩 → 안내문 → 지역별
- 카드의 **실제 항공 사진 표지는 이미 운영에 있음**(출처 문구도 이미 표시). 이번에는 건드리지 않음. 일러스트는 홈에만.
## 지킨 규칙
값·저장·계산·링크·앵커(#album/#today) 변경 0. 마크업은 옮기기만 함(내용·문구·데이터 훅 그대로, 시험으로 고정). 가짜 건물 그림 추가 0, 새 희귀도 0.
## 확인(데모, 카드 5장 모음, 320·390·430 밝은/어두운)
빈 상태: 맨 위에 빈 안내. 모은 뒤: 카드 격자 시작 위치 2,468→약 790px. 가로 넘침 0, 화면 오류 0. 어두운 화면 읽힘 확인.
새 시험 5개 + 변이 4종(오늘 후보를 다시 위로·옛 제목·격자 순서·배지 구역 삭제) 모두 실패 확인. 기존 시험 1건은 새 순서에 맞게 문구만 갱신(낮추지 않음). 전체 Node 116 / Python 579.
