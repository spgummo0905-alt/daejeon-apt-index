# D2 현장 체크 진행 카드 (시안대로, 사장님 확정)
현장 체크 시트 위쪽에 시안의 **'오늘의 현장 체크 n/N' 진행 카드 + 막대**를 추가. 값은 아래 체크리스트가 이미 세는 체크 수(`fmProg`)를 그대로 비추기만 함.
- 항목이 없으면 숨김. 막대는 장식(`aria-hidden`), 움직임은 줄이기 설정을 따름.
- 카드 안 문구: '확인한 항목 수예요. 저장 상태는 아래 줄에 따로 표시해요.' → 진행률이 저장 성공을 뜻하지 않음을 분명히 함.
- 아래 고정 줄(체크 n/N · 저장 상태 · 오늘 다녀왔어요), 저장 확인 뒤에만 켜지는 완료 카드, 저장 키·형식, 계정 분리는 변경 0.
## 확인(데모, 390폭 밝은 화면)
체크 0→1→2→1개(되돌림)에서 카드 숫자·막대(0%·8%·17%·8%)가 체크리스트 숫자와 항상 같음. 저장 성공 표시(`fm-save.ok`)와 완료 카드는 체크만으로는 나타나지 않음. 가로 넘침 0, 화면 오류 0. 화면으로 겹침·잘림 없음 확인.
새 시험 6개 + 변이 5종(저장 성공과 연결·저장 호출 끼워 넣기·항목 없어도 보임·움직임 줄이기 무시·막대 노출·카드를 아래로) 모두 실패 확인(처음 시험이 '저장 성공과 연결'을 못 잡아 시험을 보강함). 기존 시험 3건이 글자 13px를 잡아 14px로 고침(시험은 낮추지 않음). 전체 Node 116 / Python 585.
