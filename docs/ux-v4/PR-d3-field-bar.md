## 바꾼 것 (저장·체크·다녀옴 규칙·문구는 그대로)
1. **칸 순서**: 체크리스트 -> 들은 호가 -> 임장 코스 -> 지금 어디쯤 -> 사진 -> 메모 -> 방문 기록 (전: 코스 -> 어디쯤 -> 체크리스트 -> 호가).
2. **아래 고정 줄**: `체크 n/N` + 저장 상태 문구 + `오늘 다녀왔어요`(큰 버튼 52px). 값은 기존 칸(체크 수·저장 문구·다녀왔어요 단추)을 읽어 비출 뿐이고, 버튼은 기존 단추를 눌러 줌 -> 저장 확인 뒤에만 켜지는 규칙·도장·다음 단지 안내가 그대로.
3. 저장 실패면 줄이 두 줄로 바뀜: 문구(윗줄) + `다시 보내기`·`오늘 다녀왔어요`(아랫줄 나란히).
4. 키보드가 올라오면(kb-open) 줄이 숨어 입력칸을 가리지 않음. 프로젝트 안 임베드 화면에서는 줄을 숨김(기존 화면 구성 유지).
## 확인 (데모 빌드, 320·360·390·430폭)
- 줄이 4개 폭 모두 시트 맨 아래에 붙음(맨 위·맨 아래 스크롤 모두), 가로 넘침 0, 앱 오류 0, 다녀왔어요 버튼 52px.
- 체크 1개 누르면 줄이 `체크 1/12`로, 기존 제목 옆 `1/12`와 같음. 줄의 다녀왔어요를 누르면 기존 단추·도장·저장이 같이 켜지고 다시 누르면 같이 꺼짐.
- 저장 실패 흉내(화면이 읽는 상태값만 바꿈, 저장 코드는 건드리지 않음): 두 줄 구성, 글자 잘림 없음. 키보드 상태에서 줄 숨김 확인.
- 체크리스트가 첫 화면에 6~9개 보임(전: 4개), 저장 문구·다녀왔어요가 항상 보임(전: 1,283px·1,364px 아래).
