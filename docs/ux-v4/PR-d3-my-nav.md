## 고친 것 (화면 구성·저장 키·숫자 계산은 그대로)
1. **관심 단지·임장 코스·다녀온 집 숫자 칸이 눌림 없이 그냥 글자였음** -> 칸 전체가 링크. 누르면 해당 칸(탭)으로 바꾸고 목록이 탭 바 바로 아래에 오게 이동(다녀온 집 = 방문 기록 -> 임장 노트 -> 코스 순으로 보이는 첫 구역). 키보드 Enter, 눌림 효과(120ms, 줄이기 설정이면 없음) 포함.
2. **내 후보·임장·최근설정 탭을 누르면 맨 위로 가서 카드첩 가로 목록이 화면을 차지** -> 맨 위가 아니라 탭 바가 화면 위에 붙는 자리로 올려 탭 내용이 바로 보이게. ('기록 정리하기' 같은 안내 단추도 같은 이동)
3. **카드첩·임장 배지 입구가 위(내 카드첩)와 아래(카드첩 · 임장 배지 카드) 두 곳** -> 아래 중복 카드와 그 요약 코드 제거. 위 '내 카드첩'의 '49장 모음 · 임장 배지 10/14개' 줄과 '카드첩 열기' 링크는 그대로. (전체 메뉴의 카드첩 링크는 메뉴라 그대로)
