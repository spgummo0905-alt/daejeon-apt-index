# D3 내 카드 모아보기 타일 이름 두 줄까지 (사장님 요청: '이름을 두 줄까지만 보이고 줄이자')
타일의 단지 이름을 **두 줄까지만** 보이고 넘치면 …로 줄임(`line-clamp: 2`). 글자 크기는 그대로, 단어 중간에서 끊지 않음(`word-break: keep-all`, 너무 긴 단어만 끊음).
- 전체 이름은 길게 누르면 보이는 말풍선(`title`)과 음성 안내(`aria-label`)에 그대로 있음. 보이는 이름 글자·링크·값·저장 변경 0.
## 확인(데모, 아주 긴 이름 + 보통 이름, 320·390·430 밝은/어두운)
이름 두 줄 이내, 타일 높이 94px(320폭 87px)로 세 타일 같음, 가로 넘침 0, 화면 오류 0. 화면으로 …표시와 단어 단위 줄바꿈 확인.
새 시험 3개 + 변이(두 줄 제한 풀기·줄바꿈 규칙 제거·전체 이름 title 제거) 모두 실패 확인(처음 시험이 제한 풀기를 못 잡아 보강). 중간에 시도한 '괄호 앞 줄바꿈'은 화면에 효과가 없어 되돌림. 전체 Node 116 / Python 582.
