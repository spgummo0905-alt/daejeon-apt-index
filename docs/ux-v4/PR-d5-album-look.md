# D5 카드첩을 시안 A 모양으로 (사장님: '카드첩 부분 내가 보낸 시안과 다른데?')
이전 D1은 **순서만** 바꿨고 모양은 시안처럼 맞추지 않았음. 이번에 시안 A와 나란히 놓고 구역별로 맞춤.
- **머리:** '내가 모은 집들' 오른쪽에 책 아이콘 상자(민트).
- **안내 띠:** 민트 띠('수집한 기록이 차곡차곡')를 구역 바로 위로(시안 위치).
- **구역 제목:** '살펴본 아파트 카드' → **내 카드 모아보기** + 오른쪽 **'N장 수집'** 알약. 등급 칩 → 카드 격자 순.
- **등급별 대표 카드:** 승인된 타일(이름 두 줄)은 유지하되 제목을 '등급별 대표 카드'로 구분하고 카드 격자 아래로.
- **수집 현황 줄**(시안): '수집 현황 5 / 51장' + 민트 막대. **안내 박스**(시안): 방패 아이콘 + '수집과 실제 방문 기록은 구분해요.'(기존 안내문은 그대로 담음).
## 지킨 규칙
값·수집 수·저장·계산·링크·#album 앵커 변경 0(알약과 현황은 기존과 같은 수). 시안의 건물 그림 카드는 가져오지 않음(규칙: 가짜 건물 그림 금지, 우리 카드는 실제 항공사진). 시안의 '12장 수집·예시', '92.4' 등은 가상 값이라 쓰지 않음.
## 확인(데모 5장 모음, 320·390·430 밝은/어두운)
빈 상태: 띠·알약 '0장 수집'·타일 숨김 / 모은 뒤: 띠 나타남, 가로 넘침 0, 화면 오류 0. 처음에 안내 띠가 영영 숨겨지는 버그(구역 밖으로 옮기며 찾는 범위가 깨짐)를 화면 확인 중 발견해 고침 + 시험으로 고정.
새 시험 7개 + 변이 5종 모두 실패 확인. 기존 시험 4건은 새 제목·순서에 맞게 고침(낮추지 않음). 전체 Node 116 / Python 598.
