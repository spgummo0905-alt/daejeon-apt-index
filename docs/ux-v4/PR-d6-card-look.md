# D6 카드첩 카드 모양을 시안 A대로 (사장님: '아니 시안처럼 해달라니까')
D5에서 카드를 '작은 채로 두는 게 안전하다'고 제가 마음대로 빼 두었던 것을 시안대로 맞춤. **카드첩 격자에서만** 적용(홈·MY·비교·상세 카드는 그대로).
- 맨 위: **JIPGAM ✦ S TIER** (영어 라벨, 시안) · 사진(실제 항공사진, 비율 4:3로 키움) · 이름 · **지역(이름 바로 아래 줄)** · 아래: **[다녀옴 도장(기울임)] [집감 지수 큰 금색 숫자 + 84㎡ 추정 가격]**
- '신고가' 표시는 이름을 가리지 않게 지역 줄 끝으로, 뒤집기 버튼 자리(32px)를 비워 가격을 덮지 않게.
## 지킨 규칙
값·링크·뒤집기·다녀옴 도장 조건(`DJ.been`)·84㎡ 추정 표시 그대로, 자리만 옮김(새 계산·저장 없음). 시안의 건물 그림·'예시 지수' 같은 가상 값은 가져오지 않음(실제 항공사진, 실제 값). D(밝은) 카드는 큰 숫자를 짙은 색으로.
## 확인(데모, 320·390·430 밝은/어두운)
카드 5장 모두 겹침 0, 글자 삐져나옴 0, 가로 넘침 0, 화면 오류 0. 화면으로 신고가가 이름을 가리고 뒤집기 버튼이 가격을 덮던 것을 발견해 고치고 다시 확인. 새 시험 6개 + 변이 6종 모두 실패 확인(처음 시험이 '지역 줄 삭제'를 못 잡아 보강). 전체 Node 116 / Python 604.
