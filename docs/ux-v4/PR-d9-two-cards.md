# D9 내 카드 모아보기: 최근 두 장만, 나머지는 '더 보기'
- 처음엔 **최근에 모은 두 장**만 보이고, 그 아래 'N장 더 보기 ⌄' 버튼(높이 48px) → 누르면 12장씩 펼침. 칩·수집 현황·방패 박스가 바로 보임
- 정렬: 모은 날짜 최신순(같은 날이면 나중에 담긴 순). 기존엔 등급순
- 값·저장·칩 개수·다녀옴 도장 조건 그대로
확인(데모 320/390/430 밝/어두운): 5장 모음 → 2장+'3장 더 보기', 누르면 5장·버튼 사라짐, S등급 칩 → 2장, 가로 넘침 0, 오류 0. 전체 Node 116 / Python 607, 새 시험 5개 변이 5종 확인.
