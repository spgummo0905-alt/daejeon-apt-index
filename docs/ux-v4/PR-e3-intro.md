# E3 지역 소개 화면(폰) 새 첫 화면 (Draft: 사장님 OK 후 병합·배포)
디자인 방향(Opus): 크림 홈과 같은 가족 · 제목 '임장 전에, 카드 한 장.' · 한 문장 · 일러스트 위 S~D 등급 카드 부채 · 버튼 둘(우리 동네 카드 보기/지도로 보기). 검색·예산 칩은 아래로(코드 유지). 아래 구간은 크림/흰색, 어두운 초록 면 없음, 내용은 처음부터 보임.
값: 앞 S 카드는 실제 1위 단지(이름·지역·지수), 뒤 4장은 등급 글자만. 가짜 값 없음. 큰 화면·맨 앞 주소(landing)는 기존 그대로.
확인(데모 320~430·밝/어두운): 다섯 등급 글자 모두 온전히 보임, 넘침 0, 오류 0, 움직임 줄이기 시 처음부터 펼침. 전체 Node 116 / Python 640, 새 시험 9개 변이 확인.
