# 나의 집감 '내 설정' 박스가 위 박스에 붙던 것 수정
사장님이 폰에서 직접 짚어 주신 문제(2026-11-14). CSS 한 줄.
## 원인
`.prefs` 규칙이 `margin: 0 0 16px`(위쪽 0)이라, '최근·설정' 탭에서 '최근 본 단지' 박스 바로 아래에 '내 설정'이 틈 없이 붙음. 다른 박스(`.panel`)는 위쪽 16px.
## 고친 것
`.prefs { margin-top: 16px; }` (파일 맨 끝 블록). 아래 간격·접힘 동작·'내 정보' 화면의 설정 구역은 그대로.
## 확인 (데모, 320·390폭)
- 두 박스 사이 간격 0 -> 16px, 가로 넘침 0, 설정을 펼쳐도 정상. 390폭 캡처를 눈으로 확인.
- 새 시험 1개(규칙을 지우면 실패하는 것 확인). 전체 시험 Node 실패 0 / Python 517 통과.
