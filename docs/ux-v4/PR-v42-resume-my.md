## 바꾼 것
- **지역 첫 화면(휴대폰)**: 이 기기에 저장된 최근 본 단지(없으면 관심 단지)를 읽어 제목 바로 아래에 "이어서 보기" 카드 한 장, 관심 2곳 이상이면 "관심 집 N곳, 나란히 볼까요?" 줄(비교 화면으로 가는 링크). 기록이 없으면 아무것도 안 보임(처음 온 사람은 기존 그대로). 자동 이동 없음, 눌러야 이동. 새 파일 `static/resume.js` 는 `DJ.recent()`·`DJ.favs()` 를 읽기만 함.
- **MY 숫자 3칸**: 각 칸 위에 단계 이름(1 담아 둔 집 · 2 가 볼 곳 · 3 다녀옴), 0인 칸은 흐리게. 칸 이름·값·계산은 그대로.

## 지킨 것
저장 키·값 형식·URL·점수·가격 계산·계정 분리 불변(코드에 저장 쓰기 없음, 시험으로 단언). 지역 목록(index)의 기존 `data-resume` 줄과 이름이 겹치지 않게 `data-it-resume` 사용(처음 만들 때 겹쳐 기존 줄이 섞여 들어가는 것을 화면에서 발견해 고침).
