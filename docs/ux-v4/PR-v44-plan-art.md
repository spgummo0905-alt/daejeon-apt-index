# UX v4.4 · 배치도 도면 스타일 + 상세 큰 카드 그림 교체 (ux/v44-plan-art)
기준 main `3d83e7f`. 사용자 의견: "배치도가 짜친다, 그럴싸하게 멋지게".

## 바꾼 것
- 새 공용 파일 `static/planart.js`: 배치도를 **도면처럼** 그림 (남색 바탕 + 가는 격자, 동마다 흐린 그림자(높을수록 길게), 흰 얇은 외곽선, 방위표 N, 높이 범례(낮음→높음 띠), 상세는 축척 막대).
- 값은 새로 만들지 않음: 동 위치·층수·'추정' 표시는 일조 미리보기 자료(plans.json) 그대로. 층수 → 색 기준은 모든 단지 같음.
- 수집 카드(cover.js)가 같은 그림을 씀. 라벨 '배치도'는 왼쪽 아래, 범례는 오른쪽 아래. 작은 카드(128px)는 라벨 숨김(기존).
- **상세 맨 위 큰 카드**: 야경 건물 그림(그림이라 실제와 다름) → 같은 배치도. 자료 없는 단지는 가짜 건물 대신 빈 도면 + '건축물 자료가 없어 배치도를 그리지 않았어요'.
- 글자는 모두 12px 이상(라벨), 가로 넘침 없음.
