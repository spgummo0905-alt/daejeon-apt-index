# UX v4.5 · 상세 큰 카드 = 단지 입지 지도 (ux/v45-location-map)
기준 main `3d83e7f`. #373(배치도)을 대체합니다. 사용자 의견: '사람들이 원하는 건 우리 단지가 어떤 위치인지 한눈에 알 수 있는 직관적인 이미지'.

## 결정 이유 (대안 비교)
- 평면 배치도(#373): 도면 같지만 '어디 있는 단지인지'를 말해 주지 않음 → 폐기
- 입체 단지 모형: 아파트 느낌은 나나 외관이 실제와 달라 오해 소지, 위치 정보 없음 → 폐기
- **입지 지도(채택)**: 단지를 가운데 두고 구 경계, 주변 단지 점, 주요 중심지(직장·학원가) 방향·직선거리, 1km 고리. 실제 좌표만 사용.

## 바꾼 것
- 새 `static/locmap.js` + 빌드가 만드는 `locmap.json`(통계청 구 경계 + 설정의 직장·학원가 좌표). 새로 만든 값 없음.
- 상세 큰 카드 그림 칸 = 입지 지도. 순위·실거래 배지가 덮는 위·아래 띠를 비워 가림 없음. 이름표가 겹칠 자리면 그리지 않고, 거리는 지도 아래 14px 글줄에 항상 표시. 좌표·지도 자료가 없으면 옛 그림 그대로.
- 수집 카드는 항공 사진 그대로(배치도 코드·plans.json 제거).
- 역·학교·마트·병원은 좌표가 없어 그리지 않음(거리 숫자는 기존 '입지' 칸).
