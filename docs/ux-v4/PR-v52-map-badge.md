# UX v5.2 · 위치 지도 새 안 + 배지 알림 대신 MY 점 (ux/v52-map-badge)
Fable(시각)·Opus(고객 여정) 2라운드 토론의 합의안.
## 위치 지도
- 이름 없는 점 100여 개, 마름모, 점선, 다른 구 경계, 지도 위 순위·배지·가격 상자를 모두 뺌. 남은 것: 단지 이름, 우리 구(칠함), 실선 반경 1km 원, 가까운 중심지 이름표(이름+거리, 화면 밖은 화살표).
- 지도 위 제목줄 '위치 · 직선거리' + '실제 지도로 보기'(map.html?s=단지).
- 지도 아래: 역·초등학교·대형마트 거리(단지 중심 직선거리), 병원은 반경 1km 안 개수. 값이 없으면 칸째 숨김('-' 없음).
- 가격: '최근 실거래(면적)'와 '84㎡로 맞추면(추정)' 나란히 + 면적이 다르다는 한 줄. 순위: '지수 산정 N곳 중 K위'(조건 찾기 '전체 570곳'과 기준이 달라 '지수 산정'으로 명시).
- 이름표 겹침 방지: 자리 예약 후 8방향 시도, 못 그린 것은 지도 아래 글줄. 360폭 미만은 이름표 2개.
## 배지 알림
- '배지를 받았어요' 알림을 띄우지 않고 MY 메뉴에 작은 빨간 점. MY·카드첩을 열면 사라짐. 점 상태는 탭 임시 저장(sessionStorage)이고 기록 저장소·키·형식은 그대로.
## 안 한 것(사실 확인 후)
- 걷는 시간·'걸어서' 표현, 학교 종류 추측, 마트·병원 위치를 지도에 그리기(좌표 없음).
- 지도 위 기차·책·집 아이콘의 기능 확인은 이번에 글자 이름표로 바꿔 해결(기차→역 이름 거리, 책→학원가는 이름표, 집→'N세대' 글자 버튼).
