# UX v5.5 · 편의 단추 (ux/v55-convenience)
토스·팬텀 조사에서 집감에 비어 있던 것만 추가. 이미 있는 것(최근 본 목록, ㎡/평 전환, 비교함 담기, 공유, 되돌리기, 현장 모드)은 중복 구현하지 않음.
- 자기자본 빠른 단추(+1천만/+5천만/+1억/지우기, 높이 44px) + 입력 금액 한글 읽기('= 1억 6천만원', aria-live). 계산·저장(pay) 그대로.
- 위치 머리줄 '길찾기 ›'(카카오맵 도착지 링크) + 기존 '실제 지도 ›' 유지.
- 관심 담기 시 8ms 진동(DJ.tap): 줄이기 설정·미지원 기기는 무동작.
