# UX v6.1 · 좁은 폰에서 입지 점수 줄 가로 넘침 (ux/v61-seoul-360)
발견: 서울 단지 상세를 360px 폭에서 열면 화면이 2px 가로로 밀림(320px에서는 42px, 대전은 320px에서 12px). 원인은 '주변 중학교 순전입률' 줄의 최소 폭(329px)이 칸(294px)보다 넓은 것.
- 400px 이하에서 입지 점수 줄의 제목 칸이 줄어들며 줄바꿈되게 함. 점수·거리·순위 값은 그대로, 묶음 제목 줄은 그대로.
## 검증: 운영 서울·대전 상세에 새 CSS를 덮어 320/360/390px 측정 -> 가로 넘침 모두 0, 줄 높이 47px 유지.
