## 해결하는 것
운영에서 직접 확인(대전·390폭): 비교 -> '임장 코스 보기' -> MY 임장 코스 첫 화면(위 844px)에 눌러야 할 버튼이 없음. 설명·검색칸·모드·숫자 4칸·안내 박스를 지나 스크롤해야 '현장 체크 시작'이 나옴.
## 변경
- 임장 코스 설명 바로 아래에 큰 버튼 '현장 체크 시작 · 첫 단지 <이름>'(다녀온 단지면 '현장 체크 이어서 하기')와 요약 한 줄(곳 수·직선거리·이동 예상).
- 첫 단지의 기존 '현장 체크 시작' 버튼과 같은 주소(`apt/<단지>#field`)로만 이어짐. 단지가 2곳 미만이면 숨김.
## 지키는 것
저장 키·형식, 코스 순서·거리·시간 계산, 현장 모드, 기존 단지별 버튼(그대로) 불변. 새 버튼은 저장하지 않음.
## 확인(데모 사이트, 390/360/1280)
버튼 높이 56px, 첫 화면 안, 기존 버튼과 같은 주소, 가로 넘침 0, 오류 0, 클릭 시 단지 현장 모드로 이동·코스 저장값 불변, 코스 없으면 숨김.
