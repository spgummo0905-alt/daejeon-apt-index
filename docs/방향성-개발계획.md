# 집감 방향성과 개발 계획 (2026-11-04)

## 방향 (바뀌지 않는 것)
- 임장을 쉽고 재미있게. 쉬운 말과 직관적인 점수로 한눈에, 정보는 카드 한 장에.
- 핵심 흐름: 검색 → 후보 담기 → 비교 → 방문 계획 → 현장 기록 → 재비교.
- 핵심 기능은 무료로 열어 두고, 로그인은 저장용. 결제·가격 실험은 보류하고 구조만 유지.
- 지킬 선: 투자수익 보장 표현 금지, 판단어 대신 숫자, 없는 데이터는 그리지 않음, 개인 메모·사진·고객 이름은 분석에 보내지 않음.

## 지금 상태 (잰 값만)
- 테스트: 파이썬 210개, 브라우저 60개 통과.
- 접근성·모범사례·검색: 100 (이전 측정). 속도(휴대폰): 운영 대전 홈 69~91로 흔들림, 시험 환경 상대 비교로 글꼴 개선 61 → 67~70.
- 남은 속도 병목: 스타일 파일 346KB(압축 전 기준)가 화면 표시를 막음, 큰 데이터 파일 82KB.
- 앱: 비공개 테스트 단계. 테스터 12명 이상, 14일 이상 필요.

## 우선순위 (위에서 아래로)
1. 운영·기록 안전: 저장 실패 알림(완료), 방문 기록 고치기(완료), 서비스 점검 알림 문구.
2. 첫 이용·검색: 첫 화면 속도(진행 중), 통계 카드 숫자 뜻 정리, 제목 속 지역 단어 표시 정리.
3. 단일 화면: 큰 구역 9개로 11,000px가 넘는 지역 홈 길이 줄이기(접기·요약).
4. 방문 전후: 다녀온 뒤 정리(완료), 방문 계획 알림.
5. 후보 요약: 내 조건 기준 비교(완료), 비교 결과 공유 카드.
6. 공유·재방문: 링크 미리보기 카드(완료), 앱 설치 안내.

## 이번 주 할 일
- [속도] 스타일 파일 줄이기(주석·공백 제거, 새 도구 없이 빌드 과정에서), 스크립트 로딩 순서 점검. 같은 조건으로 번갈아 3번씩 재서 효과가 있을 때만 합침.
- [화면] 통계 카드에서 "비교한 아파트"와 "지수 산정" 숫자가 나란히 있어 헷갈리는 점 정리.
- [화면] 지역 홈 제목 안 지역 단어의 점선·화살표가 PC에서 다음 줄과 겹쳐 보이는 점 확인.
- [화면] 글자 크기 종류(10~31px 사이 20가지 이상)와 모서리 값(13가지)을 단계표로 모으기. 한 번에 하지 않고 화면 하나씩.

## 하지 않는 것
- 3D·애니메이션 그림, 카드 금박·백금박 정체성 약화.
- 새 외부 라이브러리 추가.
- 결제·관리자 기능, 사용자 데이터를 분석 서비스로 보내는 일.

## 측정할 것
- 유입, 탐색 성공, 활성화, 깊은 사용, 재사용, 품질·비용. 대표 지표는 "비교 → 현장 기록 → 재비교"를 끝낸 프로젝트 수.
- 속도는 같은 조건에서 번갈아 3번 이상 잰 값만 보고에 씀.
