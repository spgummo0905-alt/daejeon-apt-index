# 집감 사용성 테스트 시나리오 (5명용)

> **이 문서는 시험 방법만 적었습니다. 아직 실제 사용자 테스트는 하지 않았고, 결과는 비어 있습니다.**
> 자동 점검(브라우저 시나리오)은 "화면이 끝까지 동작하는가"만 확인합니다. "사람이 설명 없이 이해하는가"는 사람에게 시켜 봐야 알 수 있습니다.

## 1. 목적

설명 없이 처음 보는 사람이 다음 세 가지를 스스로 해내는지 확인합니다.

1. 내 조건에 맞는 집 후보 찾기
2. 후보 2~3곳 비교하기
3. 임장(방문) 계획 세우고 현장에서 기록하기

## 2. 참여자 (5명)

| 구분 | 인원 | 이유 |
|---|---|---|
| 집을 처음 알아보는 사람 | 2 | 용어·시작점이 막히는지 |
| 임장 경험이 있는 사람 | 2 | 기존 방식(메모·엑셀)보다 편한지 |
| 50대 이상 | 1 이상 (위 4명과 겹쳐도 됨) | 글자 크기·메뉴 발견성 |

- 가족·지인이어도 되지만, **집감을 써 본 적 없는 사람**이어야 합니다.
- 기기: **본인 휴대폰** (모바일이 기본). 가능하면 1명은 데스크톱.
- 시험 지역은 대전으로 통일해 결과를 비교하기 쉽게 합니다.

## 3. 진행 방식

- 진행자는 **설명하지 않습니다.** 막혀도 먼저 알려주지 않고, 30초 이상 막히면 "지금 뭘 찾고 계세요?"라고만 묻습니다.
- 소리 내어 생각하기를 부탁합니다. ("지금 뭘 누르려는지, 왜 그런지 말해 주세요.")
- 화면 녹화 동의를 받으면 녹화, 아니면 진행자가 기록표에 적습니다.
- 한 명당 약 20분. 끝나고 3가지 질문(아래 6번).

## 4. 과제 (참여자에게 소리 내어 읽어 주는 문장)

**과제 A. 집 찾기** — "예산 6억 정도로, 30평대 아파트를 알아보려고 해요. 마음에 드는 곳 두 군데를 찾아서 저장해 보세요."

**과제 B. 비교하기** — "방금 저장한 두 곳 중에서 어느 쪽이 나은지 비교해 보세요."

**과제 C. 임장 준비** — "주말에 두 곳을 직접 보러 가려고 해요. 어떤 순서로 갈지 정하고, 현장에서 확인할 걸 준비해 보세요."

**과제 D. 현장 기록** — "한 곳에 도착했다고 치고, 확인한 것을 기록해 보세요. (예: 소음이 있었다, 주차가 불편했다)"

**과제 E. 정리** — "다녀온 뒤 두 곳을 정리해서, 가족에게 보여 줄 한 장으로 만들어 보세요."

## 5. 기록표 (과제마다 한 줄)

| 항목 | 기록 방법 |
|---|---|
| 완료 여부 | 혼자 완료 / 힌트 후 완료 / 실패 |
| 걸린 시간 | 초 단위 |
| 막힌 곳 | 어느 화면, 어떤 버튼 앞에서 멈췄나 |
| 잘못 누른 곳 | 예상과 다른 곳을 누른 횟수 |
| 한 말 | 헷갈린다·찾을 수 없다 등 원문 그대로 |
| 안 보인 것 | 있는데 못 본 버튼·안내 |

**특히 볼 곳(이번 UX 개선이 실제로 효과가 있는지):**
- 홈 첫 화면에서 "조건으로 찾기 / 비교 / 임장 준비" 입구 3개를 바로 찾는가
- 단지 상세에서 "비교" 버튼을 바로 누르는가
- "임장 준비"라는 이름을 보고 무엇인지 짐작하는가
- 토스트(잠깐 뜨는 알림)를 놓쳤을 때 다음 행동을 다시 찾는가
- "다녀왔어요" 저장 후 안내를 보고 다음 단지로 넘어가는가
- 예산을 정한 뒤 상세 카드의 "내 예산보다 ○○ 낮아요/높아요" 줄을 읽는가, 오해하지는 않는가(판단으로 받아들이는지)
- 글자가 작아서 읽기 어려운 곳이 있는가

## 6. 끝나고 묻는 3가지

1. 가장 헷갈렸던 곳은 어디였나요?
2. 이 앱이 없다면 지금까지 어떻게 하셨을 것 같나요?
3. 친구에게 추천한다면 한 문장으로 뭐라고 하시겠어요? (설명을 시키지 말고 그대로 받아 적기)

## 7. 판단 기준 (미리 정해 두기)

- 과제별 **혼자 완료 비율 80% 이상**(5명 중 4명)이면 통과.
- **3명 이상이 같은 곳에서 막히면** 우선 고칠 문제로 분류.
- 1명만 겪은 문제는 기록만 하고 보류(다음 테스트에서 재확인).
- 고친 뒤에는 **다른 사람 3명**에게 같은 과제만 다시 시킵니다(같은 사람은 학습 효과가 있어 제외).

## 8. 하지 말 것

- 결과를 짐작해서 채우지 않기. 안 해 본 테스트의 수치는 적지 않습니다.
- 참여자의 실제 메모·사진·직장 주소를 시험 데이터로 쓰지 않기(시험은 지역·단지만 고르고 가짜 메모 사용).
- 질문을 유도하지 않기("비교 버튼 보이시죠?" 같은 말 금지).
