# 안정성 강화와 핵심 임장 경험 완성: 작업 기록

기준일 2026-11-05, 브랜치 `improve/stability-core`. 새 기능을 늘리지 않고 "검색 → 후보 저장 → 비교 → 임장 코스 → 현장 기록 → 방문 후 정리"를 안정적으로 이어지게 하는 데 썼습니다.

## 이미 되어 있어 건드리지 않은 것 (코드로 확인)
- 저장 실패·계정 전환·기록 병합·게스트 기록 가져오기 회귀 시험: `tests/test_records.cjs` 16건, 프로젝트·방문 기록·요약·작업 화면 시험 약 30건
- 방문 후 정리(확인·미확인·메모): `visit-summary.js`, 프로젝트 화면 "다녀온 뒤 정리"
- 임장 노트 CSV·인쇄: `prefs.js` (관심 화면). 이번 보고서는 이것과 겹치지 않게 만듦(아래 3번)
- 서비스 워커의 화면 미리 저장과 오프라인 안내: `sw.js`
- 첫 화면 "이어서" 줄: 이번에는 진행 중인 프로젝트만 보강

## 우선순위 1: 운영 안정성

| 항목 | 문제 재현 | 수정 | 검증 |
|---|---|---|---|
| shadow.js 시험 | `\|\| true` 로 항상 성공하는 줄이 있었음 | 의미 있는 시험 4건으로 대체(새벽 back/정오 sun, 밤 night, 꼭짓점 순서 반대, 안내 문구) | 판정을 일부러 망가뜨린 변이 4종 모두 시험이 실패함을 확인 |
| 그림자 계산 결함 | 시험을 바로잡다 발견: 꼭짓점이 반대 방향으로 적히면 직사각형의 **북쪽 벽**을 남향으로 잡아 가림 판정이 틀림 | `face()` 가 바깥쪽 법선 기준으로 남쪽 면을 고름 | 신규 시험 통과 |
| 배포 오류 | 배포 흐름에 "필수 자료가 없으면 멈춤"이 없었음(실패 단계는 `continue-on-error`) | `scripts/site_gate.py`: 올리기 직전에 대전 필수·단지 수·필수 칸·단지 페이지·sitemap·서비스 워커 점검. 실패하면 배포 중단(이전 사이트 유지) | 시험 11건 + 일부러 무력화한 변이 3종 실패 확인 |

| 계정 삭제 | 사진 삭제 요청이 실패해도 계정이 먼저 지워져 공개 저장소에 주인 없는 사진이 남을 수 있었음 | 사진 삭제 응답을 확인하고, 실패하면 계정 삭제를 멈춤 | 신규 회귀 시험 2건, 수정을 되돌리면 시험이 깨짐 |
| 사진 저장소 | 공개 버킷(운영에서 확인). 이름 난수 약 31비트 | `docs/사진-저장소-감사.md`: 감사 스크립트, 비공개 전환·되돌리기 SQL(미적용), 본인 사진 서명 주소 재시도, 새 사진 이름 96비트 | 시험 7건, 운영 읽기 전용 감사로 현재 상태 기록 |

## 우선순위 2: 핵심 이용 흐름
- 진행 중인 임장 이어 하기: 첫 화면 "이어서" 줄 맨 앞에 가장 최근에 손댄 진행 중 프로젝트(보관 안 한 것, 후보 있는 것)를 보여 주고 누르면 프로젝트 화면으로. 브라우저에서 기록 없음, 여러 개와 보관본, 최근순을 확인.
- 앞서 합친 변경(범주 진입 줄, 질문 구역, 다녀온 카드 도장, 탭 이름 "둘러보기")은 같은 목표입니다. 새 화면은 만들지 않았습니다.
- 휴대폰 사용성은 이번에 보고서 버튼(높이 46px, 가로 넘침 없음)만 확인했습니다. 지도·비교 화면의 휴대폰 개선은 하지 못했습니다(남은 일).

## 우선순위 3: 한 장 보고서
- 위치: 프로젝트 화면의 "한 장으로 정리 (인쇄·PDF)". 기존 `DJVisitSummary` 와 `DJ.printSheet` 를 재사용해 새 저장 구조가 없습니다.
- 구분: 내가 정한 조건 / 후보별 공개 자료 숫자(값이 있는 것만) / 직접 확인한 것 / 아직 확인 못 한 것 / 내가 남긴 메모. 기록이 없는 후보는 "아직 다녀오지 않은 후보"에 공개 숫자만 적고, 확인 칸이나 메모를 만들지 않습니다.
- 임장 노트 CSV·인쇄와의 차이: 노트는 단지별 기록 모음, 보고서는 한 프로젝트의 조건과 후보를 같은 기준으로 견주고 미확인 항목을 따로 보여 줍니다.
- 판단어·추천 없음을 시험으로 고정. 서버 전송 코드 없음도 시험.
- 그림자·일조: 정확한 일조시간으로 표시하지 않습니다. `shadow.js` 에 안내 문구 상수를 두었고, 화면에는 아직 붙이지 않았습니다.
