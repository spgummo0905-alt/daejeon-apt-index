# 집감 운영 비용·한도 기준 (초안)

목적: 무료로 열어 두는 동안에도 비용과 남용을 확인할 수 있는 기준을 정해 둡니다. 가격·유료화 결정은 이 문서에 없습니다.

## 1. 지금 비용이 드는 곳과 확인 방법

| 항목 | 무엇에 쓰나 | 한도·비용 | 확인 방법 |
|---|---|---|---|
| 호스팅 (GitHub Pages) | 정적 사이트 배포 | 저장소 공개/비공개 정책에 따름. 사이트 용량 권장 1GB 이내 | 배포 로그의 사이트 용량 |
| 빌드 시간 (GitHub Actions) | 하루 1회 자동 + 수동 배포 | 요금제별 월 분 한도 | Actions 실행 시간 |
| 공공데이터포털 | 실거래가·단지 정보 | 개발 계정 일일 호출 한도 | 수집 로그의 호출 수. 캐시된 달은 건너뜀 |
| 카카오 로컬 API | 좌표·주변 시설 | 일일 호출 한도. 결과는 캐시하고 새 단지만 조회 | 수집 로그 |
| 카카오맵 (JS 키) | 단지 페이지 지도 | 일일 지도 로드 한도 | 카카오 개발자 콘솔 통계 |
| 네이버 검색 API | 단지 페이지 블로그 글 | 일일 호출 한도 | 수집 로그 |
| 방문 통계 (Cloudflare Web Analytics) | 방문 수·경로 | 무료. 쿠키·개인정보 없음 | Cloudflare 대시보드 |
| 이미지 | 단지별 미리보기 카드(S·A 약 700장) | 장당 약 90KB 추정, 합계 약 60MB | 배포 후 `static/og/apt` 용량 |

## 2. 남용·비용 점검 기준 (넘으면 원인부터 확인)

- 배포 사이트 용량이 800MB를 넘으면 이미지·데이터 최적화부터 합니다.
- 지도 로드가 일일 한도의 70%를 넘으면 지도를 클릭해야 열리게 바꾸는 방안을 검토합니다.
- 수집 API 오류율(429·한도 초과)이 반복되면 수집 주기를 늘립니다.
- 브라우저 저장 공간은 기기별이라 서버 비용이 없습니다. 저장 실패는 화면에서 알립니다.

## 3. 원칙

- 핵심 기능(검색·비교·임장 기록)은 로그인과 결제 없이 씁니다.
- 한도가 필요해지면 먼저 이 문서에 이유와 숫자를 적고, 별도 결정 후 화면에서 명확히 안내합니다.
- 요금제 변경이 사용자의 기록 삭제로 이어지지 않게 합니다.
- 위 숫자 중 "추정"은 실제 운영 값을 확인하면 고칩니다.
