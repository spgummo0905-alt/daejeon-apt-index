# 일조 미리보기 (정식) 기록

**성격:** 건물 윤곽(브이월드)과 건물 높이·층수(건축HUB 건축물대장 표제부)로 앞 동이 햇빛을 가리는 시간대를 **추정한 참고용**으로 계산해 보여 주는 화면(`preview.html`). 실내 채광·법적 일조권이 아니다.

## 자료와 승인
- 브이월드: 사용자(소유자)가 "사이트 활용 모두 승인받았어, 사용 가능한 정보 모두 가공 가능"이라고 말함. **서면 승낙문 원문은 아직 못 받음** (받으면 이 문서에 붙인다).
- 건축HUB: 공공데이터포털 활용신청 승인, 기존 `DATA_GO_KR_KEY`.
- 화면에 출처(브이월드, 국토교통부 건축HUB)를 적고 `noindex`.

## 만드는 법 (이 컴퓨터에서 한 번, 결과만 저장소에)
1. 브이월드 건물 윤곽·지적(필지 번호): 한국 접속 PC에서만 가능 (GitHub 실행기는 접속 불가).
2. 건축HUB 표제부: GitHub 실행기에서 필지별 호출 (1,103필지, 오류 0).
3. `scripts/preview_build.py` 로 짝짓기·등급 -> `data/preview/<지역>/<단지>.json`.
   - 동 번호가 있으면 같아야 하고, 지상 층수가 같아야 하며, 준공일·바닥 면적이 비슷하면 가점. 점수 45 미만은 짝 안 함.
   - 등급: A(아파트 동 3개 이상 + 85% 이상 짝) · B(2개 이상 + 60%) · C/D는 열지 않음.
   - 높이 우선순위: 건축HUB > 브이월드 > 층수 x 층고(추정, 단지 안 실측 중간값). 내 동에서 200 m 안의 3층(9 m) 이상 이웃만 담음.
4. 사이트 만들 때 `djdex/site.py::_preview_setup` 이 열린 단지만 `preview/` 에 싣고 목록(`list.json`)을 만든다. 지역 폴더는 `base_url` 끝으로 구분. 서울은 자료 없음 -> 아무것도 안 만든다.

## 결과
- 전체 1,175단지: A 567 · B 170 · C 367 · D 71 -> **열리는 단지 737곳**(대전 318, 세종 146, 청주 273 합 737). 자료 약 10 MB, 단지당 중앙값 11 KB(90% 22 KB, 최대 59 KB), 화면은 그 단지 파일만 불러옴.
- 정답을 아는 3개 단지(건축HUB 확인): 짝지은 동 이름 불일치 0건. 시제품과 새 계산의 동지 직사광 시간 차이는 평균 9~12분(최대 45~60분) — 이웃 건물 포함 범위를 줄인 영향.

## 한계 (화면에도 적음)
- 실제와 맞는지 외부 자료와 비교 검증은 **하지 못함**.
- 지형, 창 방향(남쪽 긴 면 가정), 나무·담장, 층별 높이는 반영 안 함. 조망은 계산 안 함.
- C 등급(윤곽이 여러 필지에 걸린 대단지 등)은 열지 않음.
- 브이월드 건물 자료의 높이는 54% 비어 있어 이웃 건물 높이는 "층수로 추정"이 많음.
